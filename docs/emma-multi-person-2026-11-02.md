# Emma กับคนหลายคน — แยกว่าใครคุย, ทักรวม, หันหาทีละคน

คำขอของเจ้าของ (2 พ.ย. 2026):

> *"ระบบจดจำและสลับผู้สนทนา (Multi-user / Session Management): ในกรณีที่มีคนเยอะ หุ่นยนต์ต้องแยกแยะได้ว่าใครกำลังคุยกับมันอยู่ (ผ่านการตรวจจับใบหน้า Facial Recognition หรือทิศทางเสียง) เพื่อไม่ให้สับสนหรือตอบคำถามข้ามคนกัน
> ระบบคิวหรือการทักทายทั่วไป (Greeting & Queuing): หากมีคนยืนล้อมรอบเยอะ หุ่นยนต์ควรสามารถทักทายรวมๆ ได้ (เช่น "สวัสดีครับทุกท่าน มีอะไรให้ผมช่วยสอบถามได้เลยนะครับ") และใช้การสบตาหรือหันหน้าไปหาทีละคน
> แล้วก็จดจำใบหน้า อาจจะต้องให้หุ่นหันไปดูตามเสียงหรือปรับกล้องให้เห็นหน้าคนแล้วไปทักทาย"*

**คำตอบสั้น:** ครึ่งหนึ่งของเรื่องนี้มีโค้ดอยู่แล้ว (ตัดสินว่าใครพูดจากปาก/ทิศ, ไม่เรียกชื่อเมื่อมีคนอื่น, ตาของ Emma หันตามคนพูด, หัวจริงหันตามคน) **แต่ข้อมูลจริงบนหุ่นบอกว่าตัวชี้ "ใครพูด" ยังไม่เคยทำงานเลยสักครั้ง** — กล้องอยู่บนหัว ระหว่างคุยเห็นหน้าคนแค่ 11% ของประโยค และตัววัดการขยับปากประมวลผลหน้า 0 หน้า ทิศเสียงจริงทำไม่ได้กับฮาร์ดแวร์ตอนนี้ (อาร์เรย์ไมค์เปิดได้สตรีมเดียว)

รอบนี้ทำ **ขั้นแรก** สองอย่าง ปิดเป็นค่าเริ่มต้นทั้งคู่ (ห้องขายและหุ่นทำงานเหมือนเดิมทุกไบต์จนกว่า robot.env จะเปิด):

1. `FACE_GROUP_GREETING` — เห็นหน้า ≥ 2 คนตอนจะทัก = ทักรวมประโยคเดียว ไม่เรียกชื่อใคร
2. `FOCUS_GAZE_VISIT_S` — มีหน้า ≥ 2 คนและไม่มีใครพูด = ตาของ Emma (และหัวจริงเมื่อเปิด HEAD_FOLLOW) ไปหาทีละคน ซ้ายไปขวา

## 1. ของที่มีอยู่แล้ว เทียบกับคำขอ

| คำขอ | สิ่งที่มีในโค้ด | สถานะบนหุ่น |
|---|---|---|
| จดจำใบหน้า | `facewatch.Watcher` (AuraFace + gallery) เรียกชื่อเมื่อผ่านเกณฑ์ + margin + consent + **อยู่คนเดียวในภาพ** (`FACE_NAME_WHEN_ALONE`: หน้าที่สองขนาด ≥ 60% ของหน้าใกล้สุด = ไม่เรียกชื่อ) | ใช้อยู่ |
| แยกว่าใครพูด | `focus.segment_closed` ตัดสินเจ้าของแต่ละประโยค: ปากที่ขยับ → หน้า, ทิศเสียงตัดสินเสมอ, เสียง (voiceprint) พาคนข้ามช่วงที่หน้าหาย → `SpeakerLabel` "คนที่ N" | ทำงาน แต่ได้ "ไม่รู้" เกือบทุกประโยค (ข้อ 2) |
| สัญญาณ "ปากขยับ" | `active_speaker.py` (2d106det, ASD_ENABLED) | **เปิดอยู่แต่ไม่ได้ผลเลย** — ประมวลผล 0 หน้า (ข้อ 2) |
| ไม่ตอบข้ามคน | ชื่อใช้แค่ประโยคทัก (`greeting_for` สั่ง "ห้ามถือว่าคนที่พูดคือ...") · ป้าย "[ผู้พูด: คนที่ N]" ส่งเป็น context note (`FOCUS_SPEAKER_LABELS`) | ป้ายปิด (ยังไม่วัดว่าค้างเทิร์นไหม) |
| คิว / คุยทีละคน | สายเดียวต่อหุ่น (session ใหม่แทนที่เก่า), `FOCUS_ENGAGE_MODE=full` = คนหลักคุมหุ่นจนเดินออก, `FOCUS_GOODBYE` = คนหลักเดินออกกลางบท → ลา → standing line เปิดสายใหม่ (บริบทใหม่) | full และ goodbye ปิด (semi) |
| ทักรวมเมื่อคนเยอะ | **ไม่มี** — คนแปลกหน้าเป็นกลุ่มได้คำทักแบบคนเดียว | **ทำรอบนี้** (`FACE_GROUP_GREETING`, ปิด) |
| สบตา / หันหน้าทีละคน | `FOCUS_ATTENTION` ตาของ Emma บนจอหันตามคนพูด ไม่มีใครพูด = มองหน้าใกล้สุด **ตลอด** | ตาเปิด · **ทีละคนทำรอบนี้** (`FOCUS_GAZE_VISIT_S`, ปิด) |
| หันหัวจริง | `HEAD_FOLLOW` (หัวตาม `focus.attention()`), วัดทิศเองก่อน (`HEAD_CALIBRATE`) | **ไม่เคยรันบนหุ่น** (robot.env false) |
| หันตามเสียง | ทิศเสียงจริงต้องใช้อาร์เรย์ (`DOA_ENABLED`) — ปิดเพราะสตรีมเดียว · แทนด้วย: เสียงดังที่หุ่นแต่ไม่เห็นหน้า = ก้มหา (`HEAD_SEARCH_TILT`) หรือหันหาคนใกล้สุดในไลดาร์ (`LIDAR_PEOPLE`, เมื่อเส้นเทียบกล้องผ่าน) | ไลดาร์ไม่ทำงานจนกว่า HEAD_FOLLOW เปิด |
| ปรับกล้องให้เห็นหน้า | `FACE_ZOOM_ENABLED` (ขอภาพครอปคมจากหน้าหุ่น), `FACE_TURN_TO_CHECK` (หมุนฐาน ≤ 30°) | zoom เปิด · หมุนฐานปิด (อยู่บนแท่น) |

**พบระหว่างสำรวจ (แก้แล้ว ไม่มีผลเมื่อ HEAD_FOLLOW ปิด):** ตา Emma อยู่บนจอ*หน้าอก*ซึ่งไม่หมุน แต่ทิศของหน้าคนวัดจากกล้อง*บนหัว* — พอหัวหันไปหาคน ทิศในภาพเข้าใกล้ 0 ตาเลยมองตรงทั้งที่หัวมองคนอยู่ ตอนนี้ `_send_attention` บวกมุมหัว (`head_follow.offset_deg()`, เป็น 0 เมื่อ HEAD_FOLLOW ปิด) ยกเว้นทิศจากอาร์เรย์ (ไม่หมุนตามหัว)

## 3. ฮาร์ดแวร์นี้ทำอะไรได้ / ไม่ได้

**ได้**
- นับหน้าในภาพกล้องหัว (ทำอยู่แล้วทุกเฟรม — `_usable` ใช้เกณฑ์เดียวกับ "มีคนอื่น") → ทักรวม
- ตา Emma บนจอหันได้ทุกทิศทันที ไม่มีราคา CPU (ข้อความ `attention` สั้นๆ เฉพาะตอนทิศเปลี่ยน ≥ 3°)
- หัวจริงหันได้ (ช่อง 7/8) แต่ช่วงยังไม่ได้วัด — ค่าเริ่ม `HEAD_PAN_MAX` 60% × 20°/100% (เดา) ≈ ±12° ซึ่งแคบกว่ามุมกล้อง (~60–70°) มาก: การหันหาคนในภาพไม่ทำให้คนอื่นหลุดภาพ
- ไลดาร์ระดับเข่าเห็นขาคนรอบฐาน (รวมคนที่ยืนใต้กล้อง) — โค้ดมี (`lidar_people`) แต่ยังไม่เคยรัน และไม่มีใครยืนยันว่ามุมบวก = ซ้าย

**ไม่ได้ (ตอนนี้)**
- **ทิศเสียงจริง:** อาร์เรย์ Bothlent ให้ Android สตรีมเดียว — ไมค์ของสาย (WebView) กับ DOA ใช้พร้อมกันไม่ได้ (วัด 10 ต.ค.: แอปเปิดก่อน = ไมค์สายได้ศูนย์ล้วน Emma หูดับ) "หันตามเสียง" วันนี้จึงมีแค่ ความดัง (เสียงที่หุ่น ≥ 0.06) + คนในไลดาร์ + กล้อง
- **จำเสียงว่าใคร:** voiceprint มี (`VOICEPRINT_ENABLED`) แต่เกณฑ์วัดจากเสียง PC ไม่ใช่อาร์เรย์ระยะไกล — ปิด
- **รู้ว่าใครพูดเมื่อหน้าไม่อยู่ในภาพ:** 89% ของประโยค
- **เรียกชื่อคนในกลุ่ม:** ไม่มี speaker ID → ชื่อใช้ได้แค่ประโยคทัก และไม่เรียกชื่อเมื่อมีคนอื่น (กติกาเดิม)
- **คุยหลายสายพร้อมกัน:** หุ่นตัวเดียว = โมเดลสายเดียว (คิว = คุยทีละคน)

**CPU:** greeter ~6 fps ≈ 73% ของหนึ่งคอร์ · ASD ตั้ง 10 fps ประมาณ 0.65–0.85 คอร์ที่สองหน้า (ประเมินจาก PC — บนหุ่นวัดได้ 0.04–0.08 คอร์ เพราะไม่ได้ประมวลผลหน้าเลย) · ขั้นแรกรอบนี้ **ไม่เพิ่มงานต่อเฟรม**: คำทักตัดสินครั้งเดียวจากจำนวนที่นับอยู่แล้ว และรอบการมองคำนวณในจังหวะ engagement (ทุก 0.25 วิ, จับคู่ไม่กี่หน้า)

**ทางทิศเสียงจริง — ทำแล้ว 2 พ.ย. ปิดอยู่ (`ARRAY_MIC`, เจ้าของ: "ต้องแก้แอปให้ถือไมค์เองและทำเส้นเสียงใหม่") → แบบ ไฟล์ ความเสี่ยง และแผนทดสอบบนหุ่นอยู่ใน [`docs/emma-array-mic-2026-11-02.md`](emma-array-mic-2026-11-02.md)** · ข้อความด้านล่างคือการวิเคราะห์ก่อนทำ (เก็บไว้เป็นเหตุผล): ให้แอปเป็นเจ้าของอาร์เรย์คนเดียวแล้วส่งเสียงคุยเอง ส่วนประกอบมีแล้วเกือบหมด (ArrayListener/ArrayBeam ใน APK, `app/array_audio.py`, `app/doa.py`) ที่ขาดคือ
- หน้าหุ่นต้อง*ไม่*เปิด getUserMedia บนหุ่นเลย และเสียงคุยทั้งหมดมาจากอาร์เรย์ — วันนี้ `array_audio` ออกแบบเป็น "หน้าตัดสินว่าเมื่อไหร่ อาร์เรย์ตัดสินว่าอะไร" (แทนเฟรมของหน้า) ซึ่งต้องรื้อ
- **อาร์เรย์ไม่มี echo canceller** — เสียงหน้าเว็บได้ AEC ของ WebView ฟรี ย้ายไปอาร์เรย์ = half-duplex + echo guard ต้องย้ายมาฝั่งเซิร์ฟเวอร์ทั้งหมด ไม่งั้น Emma ได้ยินตัวเอง
- สตรีมอาร์เรย์ตาย = สายหูดับ (ไม่มีไมค์หน้าเว็บให้ถอย) ต้องมีตัวตรวจ + แจ้ง
- APK ใหม่ + ทดสอบบนหุ่น 1–2 วัน + รีวิว · ทุกเทิร์นของทุกสายเปลี่ยนเส้นทางเสียง = ความเสี่ยงถดถอยสูงสุดของงานนี้
- ผลที่ได้: beam แบบ DS ที่ปลอดภัย +0.1..+0.4 dB (แทบไม่มี — อาร์เรย์ ~6 ซม.), MVDR +5.7..+9 dB บนห้องจำลองแต่เสียเมื่อเล็งผิด · ความแม่นของ DOA บนหุ่นยังไม่เคยวัด และ calibration ของ doa.py เรียนจากหน้า (ซึ่งกล้องหัวแทบไม่เห็นระหว่างคุย)
- **แนะนำ (ก่อนทำ):** ทำหลังขั้น 2–3 แสดงแล้วว่ากล้อง+ไลดาร์ไม่พอเท่านั้น — เจ้าของสั่งทำเลย 2 พ.ย. (ปิดอยู่ ลองบนหุ่นหลังทดสอบหันหัว+กล้อง)

## 4. แผนเป็นขั้น และสิ่งที่ต้องวัดบนหุ่นแต่ละขั้น

### ขั้น 0 — วัดก่อน (ไม่เปลี่ยนพฤติกรรม)
- **ทำไม ASD ได้ 0 หน้า:** ถอดภาพทำงาน (มี track) แต่ landmark ไม่เคยรัน = track ทุกตัวถูกกรอง (ขนาด < 0.8 × FOCUS_FACE_MIN_PX, frozen, หรือภาพจาก feed คนละขนาดกับภาพที่ตรวจหน้า) · วัด: ยืนคุย 1 ม. หน้าหุ่น 2 นาที ดูบรรทัด `asd:` (`x N` ต้อง > 0) และ `focus_label why=mouth`
- **face_seen `faces`** (ทำแล้วรอบนี้) — เก็บหนึ่งสัปดาห์: ทักกี่ครั้งที่ `faces ≥ 2`
- **HEAD_FOLLOW รอบแรก** ตามแผนใน `docs/robot-servo-limits-2026-10-31.md` — เป็นเงื่อนไขของทุกอย่างที่ใช้หัวหรือไลดาร์

### ขั้น 1 — ทักรวม + มองทีละคน (ทำแล้วรอบนี้ ปิดอยู่)
- **`FACE_GROUP_GREETING=true`:** ภาพที่ตัดสินคำทักมีหน้าใช้ได้ ≥ 2 (เกณฑ์เดียวกับ "มีคนอื่น") → ประโยคเดียวถึงทุกคน ไม่เรียกชื่อ ไม่บอกจำนวนคน ไม่พูดถึงกล้อง และหลังจากนั้นห้ามถือว่าคนพูดต่อไปคือคนเดิม
  - หุ่นโหมดโครงการ (กล้องหุ่น + condo): **อังกฤษ** ตามกติกาคำทักแรกเป็นอังกฤษ (8 ต.ค.) — `"Hello everyone, I'm Emma. Welcome to Embassy World. If there is anything I can help with, please feel free to ask."` แล้วตอบภาษาของคนที่พูด
  - ที่อื่น: **ไทย เสียงผู้หญิง** — `"สวัสดีค่ะทุกท่าน มีอะไรให้ดิฉันช่วย สอบถามได้เลยนะคะ"`
  - คำเชิญ "มีอะไรให้ช่วย" ถูกห้ามในคำทักคนเดียว (GREETING 14 ก.ย.) — ในคำทักรวมใช้ตาม**คำล่าสุดของเจ้าของ** (2 พ.ย.) เฉพาะคำทักรวมเท่านั้น
  - ท่าจับมือ: ยังตามกติกา 10 ต.ค. (ท่าทักทุกคนที่หุ่นเห็นหน้า) — ยื่นมือให้กลุ่มด้วย
  - วัดบนหุ่น: แถว face_seen `group_greeting` เทียบ `faces`; ฟังว่าพูดประโยคเดียว ไม่มีชื่อ ไม่นับคน; เทิร์นถัดไปไม่เรียกชื่อ
- **`FOCUS_GAZE_VISIT_S=3`** (ตาบนจอ, HEAD_FOLLOW ปิด) **/ 4** (เมื่อหัวจริงตามด้วย — หัวก้าวละ 60% ของ error ทุก 1 วิ ต้องการ ~2–3 วิถึงเป้า):
  - หน้า ≥ 2 และไม่มีใครขยับปาก/ไม่มีทิศเสียง → เริ่มที่หน้าใกล้สุด (= พฤติกรรมเดิมช่วงแรก) แล้วไปคนถัดไปทางขวาของหุ่น วนกลับซ้ายสุด
  - คนที่เพิ่งพูด (ประโยคที่ตัดสินเจ้าของได้) ได้ตาอีกหนึ่งช่วงหลังพูดจบ แล้วรอบเดินต่อ*จากเขา* · ปากขยับชนะทันที
  - ลำดับเก็บเป็น "ทิศในห้อง" (ทิศในภาพ + มุมหัว) — หัวหันแล้วยังเลือกคนถัดไปถูก
  - ข้อจำกัด: เยี่ยมเฉพาะหน้าที่อยู่ในภาพ (หัวหัน ±12° (เดา) กับเลนส์ ~60–70° คนในภาพยังอยู่ในภาพ) — คนนอกภาพต้องใช้ไลดาร์ (ขั้น 2)
  - วัดบนหุ่น: ยืน 2–3 คน ดูตา Emma เปลี่ยนทุก 3 วิ, ข้อความ `attention` ไม่เกิน ~1 ต่อช่วง; เปิด HEAD_FOLLOW แล้วดูแถว `head_look` `why=visit` จำนวน refused/busy (ท่าพูดจับหัว) และว่าการหันหัวทำให้ greeter ทักซ้ำไหม (หัวหัน = กล่องหน้าเลื่อน — dedupe เลื่อนกล่องตามมุมหัวแล้ว)

### ขั้น 2 — "ใครพูด" ที่ใช้ได้จริงบนหุ่นนี้
- ซ่อม ASD ตามผลขั้น 0 แล้ว**สร้างชุดวัดก่อนเชื่อ**: พนักงานสองคนผลัดกันอ่านประโยคมีหมายเลขหน้าหุ่น (ลำดับรู้ล่วงหน้า) → เทียบ ordinal ใน focus_label กับลำดับจริง: % ประโยคที่ได้เจ้าของ, % ถูก, CPU (`asd:` core) ที่ 5/10 fps
- ไลดาร์เป็นตัว "กี่คน / อยู่ตรงไหน" ระหว่างคุย (กล้องเห็นหน้าแค่ 11%) — หลังเส้นเทียบกล้องผ่าน (`lidar_people.Check.trusted`) ใช้คนในไลดาร์เป็นเป้าของรอบการมองสำหรับคนนอกภาพ
- วัด: แถว face_seen `lidar` เทียบ `faces` หนึ่งสัปดาห์ (คนเดียวขาแยก = นับสองคนไหม)

### ขั้น 3 — กันตอบข้ามคน
- **ติดป้ายผู้พูดกับผลเครื่องมือ** แบบ `reply_language` (`talk_lang`): เมื่อประโยคล่าสุดตัดสินเจ้าของได้ (conf ≥ 0.5) และ*ต่างจาก*คนก่อน → `speaker: "คนละคนกับคำถามก่อน"` ในผลเครื่องมือ — ทางผลเครื่องมือถึงโมเดลจริง (บทเรียน CLAUDE.md) ไม่เสี่ยงค้างเทิร์นแบบ context note · ช่องโหว่เดียวกับ talk_lang: เทิร์นไม่เรียกเครื่องมือไม่มีป้าย
- เลขที่ลูกค้าให้ (calc_roi merge ต่อ call) ผูกกับคน: คนใหม่ = ล้างเลขของคนก่อน (STATE ต่อ ordinal)
- ขึ้นกับขั้น 2: ป้ายจาก "ไม่รู้" 89% ไม่มีประโยชน์ — ห้ามเปิดก่อนชุดวัดขั้น 2 ผ่าน
- วัด: eval_live_qa หมวดใหม่ (สองเสียงผลัดกันเป็นข้อความ + ป้าย) — โมเดลไม่พาชื่อ/เลขของ A ไปตอบ B; แล้วบนหุ่นกับคนจริงสองคน

### ขั้น 4 — คิว / สลับผู้สนทนา
- คุยทีละคนมีอยู่แล้ว: `FOCUS_ENGAGE_MODE=full` (คนหลักคุมจนเดินออก FOCUS_HOLD_S) + `FOCUS_GOODBYE` (เดินออกกลางบท → ลา → สายใหม่ บริบทใหม่ = คนถัดไปไม่ได้ข้อมูลของคนก่อน)
- ทั้งสองปิดเพราะต้องวัดก่อน: `focus_gap` (มี 516 แถว) — คนอ่านโบรชัวร์หน้าหลุดกี่วินาที vs คนเดินออก → ตั้ง FOCUS_GOODBYE_AFTER_S
- ตัวเลือกภายหลัง: คนที่สองพูดระหว่างคนหลักคุย (NOT_MAIN) → ประโยครับคิวสั้นๆ — เสี่ยงพูดแทรก ต้องผ่าน `events.announce` และวัดก่อน
- วัด: เล่นซ้ำ focus_gap กับ log ว่า goodbye จะลาผิดกี่ครั้ง

### ขั้น 5 — ทิศเสียงจริง (ข้อ 3) — โค้ดพร้อมแล้ว (2 พ.ย., ปิด) ทดสอบบนหุ่นหลังหันหัว+กล้อง
- แบบและแผนทดสอบทีละขั้น (เส้นเสียงก่อน `DOA_FOCUS=false` → ทิศ → หันหัวตามเสียง `HEAD_FOLLOW_DOA`) + ย้อนกลับขั้นเดียว: [`docs/emma-array-mic-2026-11-02.md`](emma-array-mic-2026-11-02.md) ข้อ 6
- calibration ทิศยังต้องการปากขยับจาก ASD (ขั้น 0) — ระหว่างใช้งานจริงจะไม่เรียนเอง

## 5. ขั้นแรกที่ทำรอบนี้ (ไฟล์และการทดสอบ)

- `app/config.py` — `FACE_GROUP_GREETING` (false), `FOCUS_GAZE_VISIT_S` (0)
- `app/greeter.py` — `_is_group`, `_group_greeting`, `GROUP_GREETING_TH/EN`; face_seen บันทึก `faces` / `lidar` / `group_greeting` (ตัวเลขล้วน)
- `app/focus.py` — `_visiting`, `_visit`, `_gaze` (สถานะห้อง ล้างใน `_forget_everything`), label จำกัดหนึ่งช่วงเมื่อเปิดรอบ
- `app/session.py` — `_send_attention` บวกมุมหัว (0 เมื่อ HEAD_FOLLOW ปิด)
- เทสต์: `tests/test_greeter.py` (ปิด = ข้อความเดิมทุกไบต์ทุกเส้นทาง, ไทยเสียงผู้หญิง ไม่มีชื่อ, อังกฤษบนหุ่น, หน้าเดียวไม่ใช่กลุ่ม, แถว log) · `tests/test_engagement.py` (ปิด = หน้าใกล้สุดตลอด, รอบซ้ายไปขวา, หน้าเดียวไม่วน, คนพูดชนะแล้วรอบเดินต่อจากเขา, เริ่มใหม่หลังพัก, ลำดับในห้องเมื่อหัวหัน, ตาบนอกบวกมุมหัว) — ย้อนโค้ดทีละจุด (7 จุด) แล้วเทสต์แดงทุกจุด
- **ไม่ได้แตะ** robot.env (สวิตช์ใหม่ไม่อยู่ในนั้น) — เปิดบนหุ่น = เพิ่มบรรทัด → `robot_server.py secrets` → restart

## 6. เรื่องที่เจ้าของต้องตัดสิน

1. **ภาษาคำทักรวมบนหุ่น:** อังกฤษ (ตามกติกาคำทักแรก 8 ต.ค. — เลือกไว้ตอนนี้) หรือไทยตามตัวอย่างของเจ้าของ
2. **คำเชิญ "มีอะไรให้ช่วย"** ในคำทักรวม — ทำตามคำล่าสุดของเจ้าของ (คำทักคนเดียวยังห้าม)
3. **ยื่นมือให้กลุ่ม:** ตอนนี้ยื่นทุกคำทัก (10 ต.ค.) — คงไว้ หรือกลุ่มไม่ยื่น (`FACE_HANDSHAKE_NAMED_ONLY=true` = ยื่นเฉพาะคนที่เรียกชื่อและอยู่คนเดียว)
4. **กลุ่มไม่เรียกชื่อเลย** แม้ตั้ง `FACE_NAME_WHEN_ALONE=false` — คำทักรวมชนะ
5. **คิว:** semi (ใครก็คุยได้ — ตอนนี้) หรือ full (คนแรกคุมจนเดินออก)
6. ~~ลงทุนทิศเสียงจริง (ขั้น 5) หรือไม่~~ — เจ้าของสั่งทำ 2 พ.ย. (โค้ดพร้อม ปิดอยู่ ดู `docs/emma-array-mic-2026-11-02.md`)
