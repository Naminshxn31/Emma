## วิธีอ่านเอกสารนี้

ทุกข้อมูลติดป้ายระดับความน่าเชื่อถือไว้ เรียงจากสูงไปต่ำ:

| ป้าย | หมายถึง |
|---|---|
| 🟢 **ราชการ** | หน่วยงานรัฐไทย/ธนาคารกลาง (ธปท., กรมที่ดิน, REIC, สคบ., ราชกิจจานุเบกษา) |
| 🔵 **สถาบัน** | บริษัทที่ปรึกษาอสังหาฯ ระดับสากล / ฐานข้อมูลนิติบุคคล / เว็บธนาคารเอง |
| 🟡 **สื่อ/กฎหมายเอกชน** | สำนักข่าว สำนักงานกฎหมาย บทความวิชาชีพ |
| 🟠 **เว็บนายหน้า/บล็อก** | ใช้ได้เป็นเบาะแส ไม่ใช้เป็นข้ออ้างกับลูกค้า |
| 🔴 **ยืนยันไม่ได้** | หาไม่เจอ หรือแหล่งขัดกันเอง — **ห้ามหุ่นพูด** |

**กฎเดิมของโปรเจกต์ยังใช้:** ตัวเลขที่ไม่มีเจ้าของคือตัวเลขที่หุ่นห้ามพูด เอกสารนี้ให้ "ข้อมูลตลาดที่ตรวจสอบได้" ไม่ใช่ "ข้อมูลโครงการที่บริษัทรับรอง" — ตัวเลขของโครงการเองยังต้องมาจากฝ่ายขายพร้อมลายเซ็นเหมือนเดิม

## ⚠️ ห้าเรื่องที่ทีมขายต้องหยุดพูดตั้งแต่วันนี้

งานวิจัยรอบนี้เจอห้าข้ออ้างที่ใช้กันอยู่ แต่ **ขัดกับข้อมูลสาธารณะ** ลูกค้าที่เสิร์ชเองจะเจอ:

1. **"ไฮสปีดเทรน 3 สนามบินกำลังจะมา"** — ก.ค. 2569 กลุ่ม ซี.พี. (เอเชีย เอรา วัน) ส่งหนังสือถึง รฟท. ขอสิ้นสุดสัญญา บริษัทออกมาโต้ว่าเป็นการ "ใช้สิทธิตามสัญญา ไม่ใช่ถอนตัว" และเรื่องยังไม่จบ รอบอร์ด EEC ชี้ขาดในเดือน ส.ค. 2569 — **สถานะคือข้อพิพาทที่ยังไม่จบ ไม่ใช่โครงการที่กำลังสร้าง**
2. **"ต่างชาติได้ลดค่าโอนเหลือ 0.01%"** — ผิด มาตรการนี้ระบุชัดว่า *"สำหรับบุคคลธรรมดาที่มีสัญชาติไทย"* ลูกค้าต่างชาติจ่ายเต็ม 2%
3. **"ผลตอบแทนเช่า 7-10%"** — ตัวเลขที่วัดด้วยวิธีเปิดเผยได้คือ **5.51%** (ชลบุรี) ส่วน 7-10% มักคำนวณจากการปล่อยเช่ารายวัน ซึ่ง**ผิด พ.ร.บ.โรงแรม** และมีการจับกุมจริงในบางละมุง
4. **"เช่า 30+30+30 ปี ต่ออายุได้แน่นอน"** — ฎีกา 4655/2566 ตัดสินว่าข้อสัญญาต่ออายุอัตโนมัติแบบนี้เป็นโมฆะ
5. **"16 โครงการ 6,000+ ยูนิต"** — ยืนยันไม่ได้จากแหล่งใดเลย รวมทั้งเว็บบริษัทเอง (ไทม์ไลน์บนเว็บนับได้ 14 โครงการ)

และหนึ่งเรื่องที่ต้องรู้ก่อนลูกค้าถาม: **"Prime One" ไม่มีอยู่จริง** ค้นแล้วไม่พบโครงการชื่อนี้ในพัทยาเลย ไม่ว่าของ Empire Group หรือของใคร

🔴 ตัวเลข 50,000 นี้มาจากสำนักงานกฎหมายเอกชนหลายแห่งที่ตรงกัน **แต่ยืนยันจากประกาศ ธปท. โดยตรงไม่ได้** → ให้ลูกค้าเช็คกับธนาคารผู้โอนเสมอ

🟡 ใบเสนอราคาไม่ใช่ใบแจ้งหนี้ ไม่ผูกพันเท่าใบสั่งซื้อ ผูกพันเมื่อมีการสนองรับ (เซ็น/มัดจำ)

## ข้อ 2 · ทำไมต้องซื้อกับบริษัทไทย

### กรรมสิทธิ์ต่างชาติ — ตัวบทที่ใช้ตอบได้

🟡 **โควตา 49%** ตาม พ.ร.บ.อาคารชุด พ.ศ. 2522 **มาตรา 19** — นับจาก*พื้นที่ขายรวม* ไม่ใช่จำนวนยูนิต แยกรายอาคาร ตรวจ ณ วันโอน

คุณสมบัติผู้ซื้อต่างชาติ ต้องเข้าข่ายหนึ่งใน 4 ข้อ:
1. มีใบสำคัญถิ่นที่อยู่ถาวร
2. ได้รับอนุญาตตาม BOI
3. **นำเงินตราต่างประเทศเข้ามาไม่น้อยกว่าราคาห้องชุด** ← กรณีที่ใช้จริงเกือบทั้งหมด
4. นิติบุคคลต่างด้าวที่จดทะเบียนถูกต้อง

### จุดขายที่แข็งจริงของ freehold 🟡

**ฎีกาที่ 4655/2566** — คดีที่ภูเก็ต สัญญาเช่า 30 ปี + ต่ออัตโนมัติอีก 2 ครั้ง ครั้งละ 30 ปี (รวม 90 ปี) จ่ายค่าสิทธิต่ออายุล่วงหน้า 600,000 บาท **ศาลตัดสินว่าข้อสัญญาต่ออายุอัตโนมัติเป็นโมฆะ** เพราะเลี่ยงเพดาน 30 ปีตาม ป.พ.พ. มาตรา 540

**แปลว่า:** คอนโดที่ต่างชาติถือ freehold ในโควตา 49% **มั่นคงกว่า leasehold อย่างมีนัยสำคัญทางกฎหมาย** — นี่คือจุดขายที่พูดได้เต็มปาก และเป็นเหตุผลที่ห้ามการันตี 30+30+30 ให้ใคร

### กฎหมาย 99 ปี / โควตา 75% — สถานะจริง 🔴

| เวลา | เกิดอะไร |
|---|---|
| มิ.ย. 2567 | รัฐบาลเศรษฐาเสนอศึกษา: เช่า 99 ปี + เพิ่มโควตาเป็น 75% — ยังไม่เข้า ครม. |
| ก.ค. 2568 | ร่างแก้ พ.ร.บ.ทรัพย์อิงสิทธิ ยังอยู่ขั้นรับฟังความเห็น |
| ต.ค. 2568 | เอกชนยังเรียกร้องให้เร่ง = ยังไม่ผ่าน |
| ธ.ค. 2568 | **ยุบสภา** ร่างที่ค้างตกไป |
| เม.ย. 2569 | เลือกตั้งใหม่ ตั้งรัฐบาลใหม่ |
| ส.ค. 2569 | **ไม่พบข่าวยืนยันว่าผ่านแล้ว** |

**กฎหมายที่ใช้จริงวันนี้ยังคือโควตา 49% และเพดานเช่า 30 ปี** — ห้ามบอกลูกค้าว่ากฎหมายใหม่ผ่านแล้วหรือจะผ่านแน่ๆ

- ผิด พ.ร.บ.อาคารชุดด้วย (ใช้ห้องผิดวัตถุประสงค์) นิติบุคคลฟ้องได้
- ต้องแจ้งที่พักคนต่างชาติต่อ ตม. ภายใน 24 ชม. (ปรับ 2,000-10,000)
- 🟢 **บังคับใช้จริงในพัทยา**: 26 มี.ค. 2568 กรมการปกครอง + ตม. + เขตพัทยา จับ "โรงแรมเถื่อน" ที่ใช้กล่องล็อกกุญแจปล่อยเช่ารายวันผ่าน Airbnb/Agoda ได้ **3 แห่งในอำเภอบางละมุง**

→ **โมเดล ROI ที่อิงเช่ารายวันคือโมเดลที่อิงกิจกรรมผิดกฎหมาย** ฐานคำนวณต้องเป็นเช่าระยะยาว (รายเดือน/รายปี)

**สิ่งที่ต้องให้ผู้จัดการขายเซ็น:** yield ที่ใช้อ้างได้ % · อัตราราคาขึ้นต่อปี % · ค่าธรรมเนียมขายต่อ % — และหุ่นต้องพูด**สมมติฐานกำกับทุกครั้งที่พูดตัวเลข ROI**

# ภาคผนวก ข · ข้อมูลที่ค้นแล้วไม่มี

ต้องบอกฝ่ายขายตรงๆ ว่าสิ่งเหล่านี้ไม่มีในสาธารณะ ไม่ใช่ว่ายังหาไม่เจอ:

- ราคา/ตร.ม. และ rental yield **เฉพาะโซนจอมเทียน** จากแหล่งราชการหรือที่ปรึกษาสากล
- **occupancy rate** ของคอนโดปล่อยเช่าในพัทยา
- **absorption rate** ที่เป็นตัวเลขวัดได้
- ตัวเลขนักท่องเที่ยว**เต็มปี 2568** จากแหล่งทางการ
- ดัชนีราคาคอนโดชลบุรี**ย้อนหลัง 5 ปี**เต็มชุด
- ค่าเช่า **2 ห้องนอน** จอมเทียนจากแหล่งที่เปิดเผยวิธีวัด
- **อัตราค่าปรับส่งมอบล่าช้า** ตามสัญญามาตรฐาน สคบ. (ดึงตัวบทเต็มไม่ได้)
- โครงการชื่อ **"Prime One"** (ไม่มีอยู่จริง)
- **สถิติเช่า Empire/Orient** (เป็นข้อมูลภายในบริษัท)
