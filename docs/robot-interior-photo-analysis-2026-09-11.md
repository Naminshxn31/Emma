# ตรวจภาพภายในหุ่น: ชุดขับไหล่ บอร์ด และสาย

ภาพจากเจ้าของสามภาพ ตรวจร่วมกับผลทดลองหัวช่อง 7/8 และ disassembly ที่สำรองไว้ ไม่ส่งคำสั่งหุ่นหรือเรียก ADB ในการตรวจภาพชุดนี้ ภาพมีไฟ LED ติดบนบอร์ด จึงไม่ถือว่าไฟภายในถูกตัดจากภาพเพียงอย่างเดียว

## สิ่งที่เห็นและระดับข้อสรุป

| จุดในภาพ | เห็นอะไร | ข้อสรุปที่ใช้ได้ |
|---|---|---|
| ภาพ 1 บอร์ดใหญ่ด้านบน | บอร์ดคอมพิวเตอร์ มีฮีตซิงก์ พัดลม แบตเตอรี่เหรียญ และช่องต่อหลายชนิด | เป็นส่วนคอมพิวเตอร์หลัก ไม่ใช่หลักฐานผังช่องเซอร์โว ตัวอักษรรุ่นบน PCB ยังไม่อ่านครบ |
| ภาพ 3 ด้านบนซ้ายและล่างขวา | มอเตอร์กระบอกโลหะสองชุดบริเวณไหล่ มีสายแดง/ดำและส่วนกลไกยึดเข้าตัวหุ่น | มีฮาร์ดแวร์มอเตอร์บริเวณไหล่จริง ลักษณะเข้าข่ายมอเตอร์ DC พร้อมชุดเกียร์ แต่ต้องเห็นป้ายและทางเดินสายก่อนยืนยันชนิด/แรงดัน/วงจรขับ |
| ภาพ 3 บริเวณคอด้านขวาบน | ชุดเซอร์โวตัวถังดำ–แดงยึดกับขายึด มีสายหลายสี | เห็นเซอร์โวอยู่บริเวณคอ สอดคล้องกับผลหัวขยับที่ทดสอบแล้ว แต่ยังไม่ได้ไล่สายยืนยันว่าตัวนี้คือช่อง 7 หรือ 8 ป้ายรุ่นอ่านไม่ชัดพอ |
| ภาพ 3 ด้านบนเหนือมอเตอร์ซ้าย | บอร์ดแดง มีขั้วต่อสีเขียว ฮีตซิงก์สีดำ และหัวต่อ/จัมเปอร์สีเหลือง | เป็นจุดสำคัญที่จะตรวจวงจรขับต่อ ยังไม่ยืนยันว่าเป็น L298N หรือไดรเวอร์รุ่นใดจากรูปทรงอย่างเดียว |
| ภาพ 2 กลุ่มบอร์ดกลางภาพ | บอร์ดมี LED สีน้ำเงินและแถวหัวต่อ สายหลายเส้นลงไปด้านล่าง | ต้องเห็นเลขหัวต่อและรุ่น PCB เพื่อจับคู่พอร์ต ไม่ยืนยันว่าเป็น CH340/CP2102 หรือเลขช่องใดจากสีไฟ |
| ภาพ 2 ด้านล่าง | บอร์ดอีกชุดมีไฟเขียวและสายไฟหลายเส้น | ยังไม่ทราบหน้าที่ ไม่อนุมานว่าไฟเขียวแปลว่าเซอร์โวมีไฟ |

ภาพยังไม่เห็นภายในศอก ข้อมือ หรือนิ้ว และไม่แสดงปลายสายครบทั้งสองด้าน จึงยังนับมอเตอร์ทั้งหมดหรือยืนยันนิ้วสิบตัวเคลื่อนไหวได้ตามสเปกคู่มือไม่ได้ ไม่พบหลักฐานเพียงพอให้ระบุว่าปลั๊กใดหลุดหรือควรเสียบเข้าช่องใด

## ผลต่อการค้นคำสั่งแขน

ไม่ควรถือว่ามอเตอร์ทุกตัวในหุ่นรับคำสั่งตำแหน่ง PWM แบบเดียวกับหัว จากภาพควรตรวจเส้นทางมอเตอร์ไหล่ไปยังบอร์ดขับ และสายควบคุมบอร์ดขับกลับไปยังบอร์ดควบคุมก่อน การที่ช่อง 1/11 ตอบแต่ไม่ขยับยังอธิบายได้หลายแบบ รวมทั้งเป็นคนละวงจรหรือไฟไม่ถึง ต้องใช้ภาพป้าย/สายหรือการวัดที่เหมาะสมแยกสาเหตุ

ตรวจ `BoardBuildDataUtil.buildMotorRunPacket`, `buildMotorRunTurnLeftPacket` และ `buildMotorRunTurnRightPacket` เพิ่มแล้ว ชื่อ motor อย่างเดียวไม่ยืนยันว่าเป็นแขน จุดเรียก TurnLeft/Right ที่พบใน `FloatRecordService$RobotServiceReceiver` อยู่กับ `touchActionType`, `TOUCHROBOTRUNTYPETURNLEFT/RIGHT/RAMDOM` และ `robotIsRun` จึงมีบริบทเกี่ยวกับการหมุนตัวหุ่น ไม่ได้นำแพ็กเก็ตเหล่านี้ไปลองกับแขน

## ภาพที่ต้องเพิ่มเพื่อไล่สายได้จริง

อัปเดต: เจ้าของส่งวิดีโอเพิ่มสองไฟล์แล้ว ดู [ผลตรวจวิดีโอและเฟรมบอร์ด/ป้ายสาย](robot-interior-video-analysis-2026-09-11.md) รายการด้านล่างเป็นคำขอก่อนรับวิดีโอ ไม่ใช่คำขอให้ส่งภาพชุดเดิมซ้ำ

หลังปิดไฟหลักและไม่แตะ/ถอดสาย ให้ถ่ายเฉพาะส่วนที่เข้าถึงได้ตามปกติ:

1. บอร์ดแดงที่มีขั้วเขียวในภาพ 3 ให้เห็นตัวหนังสือบน PCB ข้างขั้วต่อ และสายที่ออกจากทุกขั้ว
2. บอร์ดที่มีไฟสีน้ำเงินในภาพ 2 ให้เห็นแถวหัวต่อ เลขช่อง และชื่อรุ่น
3. ป้ายบนมอเตอร์โลหะข้างใดข้างหนึ่ง และภาพต่อเนื่องของสายแดง/ดำไปจนถึงปลั๊กปลายทาง

ไม่ต้องแกะตัวมอเตอร์ แกะข้อแขน ถอดปลั๊ก หรือย้ายสายเพื่อทดสอบ การสลับสาย/ขั้วโดยไม่ทราบวงจรไม่ใช่วิธีระบุ mapping
