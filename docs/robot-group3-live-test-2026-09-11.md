# ผลทดสอบกลุ่มท่า 3 ด้วยกล้อง

เจ้าของอนุญาตทดสอบและยืนยันว่าพร้อมหลังนำมือ เครื่องมือ ฝาครอบ และสายพ้นกลไกแล้ว ใช้กลุ่ม 3 ที่เจ้าของระบุว่าเคยทดสอบสำเร็จ ไม่สุ่มช่องหรือกลุ่มอื่น

## ผลที่เห็นจริง

- ภาพกล้องเห็นหัวหัน และแขนด้านซ้ายของภาพจากท่าห้อยลงยกขึ้นพร้อมงอข้อศอกจนมืออยู่ใกล้ระดับหัว แขนอีกข้างยังอยู่ข้างลำตัวในเฟรมที่ตรวจ
- ช่วงเริ่มยกเห็นตำแหน่งแขนเปลี่ยนก่อนมือคนบังบริเวณมือหุ่น ต่อมามีมือคนเข้าใกล้/บังบางช่วง จึงถามแยกสาเหตุ เจ้าของยืนยันว่า “หุ่นยกเอง ไม่ได้ช่วยยก” ผลนี้ประกอบกับภาพสนับสนุนว่ากลุ่ม 3 ขับแขนได้จริงในรอบนี้
- ยังไม่แยกการขยับนิ้วแต่ละนิ้วจากภาพนี้ ไม่วัดองศาข้อต่อ ไม่ระบุช่องเซอร์โวที่อยู่ในกลุ่ม และไม่ตั้งชื่อกลุ่ม 3 ว่าจับมือ/โบกมือจากการยกมือเพียงอย่างเดียว ใช้ด้านซ้ายของภาพเป็นตำแหน่งอ้างอิง ไม่อนุมานการสะท้อนภาพกล้อง
- ตอนท้ายแขนยังยกอยู่ การส่งหยุดไม่ใช่คำสั่งกลับท่าพัก ไม่มีการส่งกลุ่ม 99 หรือสั่งคืนตำแหน่งโดยเดา

## คำสั่งและหลักฐานตอบกลับ

เริ่มช่วงอ่าน serial เวลา 07:55:01.853 UTC (14:55:01.853 เวลาไทย) วันที่ 2026-09-11 ใช้ API เดิม rearm แล้วเรียกกลุ่ม `3` ซึ่งประกอบ `#3GC1` ให้เล่นหนึ่งรอบ จากนั้นรอ 8 วินาทีหลัง API ตอบสำเร็จแล้วเรียก stop ซึ่งส่งซ้ำตามกลไกเดิมและล็อกการส่ง ไม่มีการเปิดรีเลย์ เปลี่ยน baud หรือเปิดแอปผู้ขาย

API กลุ่มตอบ `ok=true` และ stop ตอบ `stop_write_ok=true` เก็บ RX ได้ 80 ไบต์ มี `#CC` เจ็ดรายการ `#STOP+OK...` สามรายการ และ `#AGF` หนึ่งรายการ ลำดับดิบอยู่ใน serial.json; ไม่มี timestamp รายแพ็กเก็ตจึงไม่ผูก ACK ทุกตัวกับคำสั่งใดโดยเดา และไม่ถือว่า `#AGF` ที่อยู่ใกล้ stop พิสูจน์ว่าท่าเล่นครบโดยไม่ถูกขัดจังหวะ

`armed_after=false`, ไม่มี local reader timeout และกล้องไม่ล้มเหลว ภาพที่แขนค้างช่วงท้ายกับ stop ACK ยังไม่พิสูจน์การหยุดฉุกเฉินระหว่างมอเตอร์กำลังเคลื่อน ไม่ยืนยันการตัดไฟเซอร์โว

ไฟล์หลักฐานอยู่ในโฟลเดอร์ ignored ภาพย่อครอปจากเฟรมจริง ไม่มีภาพจำลองการเคลื่อนไหว ไม่แก้ฟิลด์ `physical_motion_observed=null` ในรายงาน serial เพราะตัว probe ไม่ตรวจภาพเอง ผลตรวจภาพและคำยืนยันเจ้าของอยู่ในรายงานนี้แยกกัน

สิ่งที่ทราบเพิ่มคือเส้นทางกลุ่มบนบอร์ดขับแขนได้แล้ว สิ่งที่ยังต้องค้นเพื่อสร้างท่าเองคือช่องและลำดับภายในกลุ่ม 3 รวมทั้งช่องนิ้ว ข้อสรุปจากช่อง 1/11 ที่ไม่เห็นขยับก่อนหน้านี้จึงไม่ใช่ข้อวินิจฉัยว่าแขนเสีย
