# สคริปต์ Q&A ลูกค้าเดินเข้าห้องขาย — ร่างให้ตรวจ

> เอกสารนี้ **สร้างอัตโนมัติ** จาก `data/projects/embassy_world/sales/qa_script.json` · **ห้ามแก้ไฟล์นี้ด้วยมือ**
> แก้ที่หน้า `/data-console` แล้วกดบันทึก ระบบจะเขียนไฟล์นี้ใหม่ทั้งไฟล์ ไฟล์ JSON คือต้นฉบับ

สถานะ: **ร่าง ยังไม่อนุมัติ** · ร่างเมื่อ 24 กันยายน 2569 · สำหรับทีมขายและเจ้าของโครงการอ่านตรวจทีละข้อ

เอกสารนี้ไม่ใช่บทที่ Emma ท่องคำต่อคำ เพราะ Live model พูดเอง เอกสารนี้คือ **รูปแบบคำตอบที่ยอมรับได้** ใช้สองอย่าง: ให้คนตรวจว่าคำตอบแบบนี้โอเคไหม และเอาไปเขียนเป็นกฎใน prompt กับเป็นเทสต์ภายหลัง

## อ่านตารางยังไง

แต่ละข้อมีสองคอลัมน์ เพราะตอนนี้กับหลังอนุมัติข้อมูล Emma ตอบไม่เหมือนกัน

- **ตอนนี้** = สภาพจริงวันนี้ ยังไม่มีแหล่งข้อมูลไหนผ่านการอนุมัติ ด่าน `customer_claim_v1` ปฏิเสธทุกแหล่ง Emma จึงตอบข้อเท็จจริงของโครงการไม่ได้เลย
- **หลังอนุมัติ** = เมื่อกดอนุมัติใน `/data-console` แล้ว วงเล็บ [...] คือช่องที่ค่าจะมาจากเครื่องมือค้นจริง ไม่ใช่สิ่งที่ Emma จำเอง

ถ้าคำตอบเหมือนกันทั้งสองคอลัมน์ แปลว่าข้อนั้นไม่ได้ขึ้นกับข้อมูลโครงการ

## กฎที่คุมทุกคำตอบ (ยกมาจาก prompt จริง ไม่ใช่สรุปใหม่)

1. ตอบไม่เกิน 2-3 ประโยค เว้นแต่ลูกค้าขอรายละเอียดเพิ่ม
2. **ค่าเริ่มต้นคือไม่ถามต่อ** ทำครบแล้วจบทันที ห้ามเติม "มีอะไรให้ช่วยเพิ่มเติมไหมคะ" เพื่อกันความเงียบ
3. ฟังไม่ชัดให้ถามกลับ **ห้ามเดา** ตัวเลข ชื่อ เบอร์โทร ต้องทวนยืนยันเสมอ
4. **การกระทำต้องเกิดจริงก่อนพูดว่าเกิดแล้ว** ถ้ายังไม่มีผลสำเร็จจากเครื่องมือ ห้ามพูดว่าเปิดแล้วหรือพาไปแล้ว
5. เป็น **เจ้าบ้าน** ใช้ "เรา/ของเรา/ที่นี่" ขายชีวิตที่ดีขึ้นก่อน เทคโนโลยีทีหลัง
6. **ห้ามเปิดด้วยราคา ห้ามการันตีผลตอบแทน ห้ามเร่งให้ซื้อ**
7. แนวคิดที่ยังพัฒนาอยู่ ห้ามพูดเหมือนสร้างเสร็จแล้ว
8. ที่นี่คือ **Embassy World** เท่านั้น Embassy Life และ Embassy Pattaya เป็นคนละโครงการ

## สิ่งที่เจ้าของต้องตัดสินก่อนใช้จริง

1. คำทักเปิดจะเป็นอังกฤษต่อ หรือเปลี่ยนเป็นไทย
2. จะให้ Emma พูดราคาไหม ถ้าให้ ต้องทั้งกรอกข้อมูล กดอนุมัติ และเปิดสวิตช์ `UNITS_SHOW_PRICE`
3. ประโยคปฏิเสธมาตรฐาน "ขอให้ทีมขายยืนยันนะคะ" ใช้คำนี้ได้ไหม หรืออยากได้คำอื่น
4. เมื่อผลค้นระบุว่าเป็นแนวคิดเบื้องต้น จะให้พูดกำกับด้วยประโยคไหนทุกครั้ง
5. ข้อมูลระดับผู้พัฒนาที่ใช้ร่วมกับโครงการอื่นได้ มีอะไรบ้างนอกจากรางวัลและจำนวนโครงการ

## ขั้นต่อไปหลังตรวจ

คำตอบที่ผ่านการตรวจแล้วจะถูกแปลงเป็นสองอย่าง: กฎใน `app/prompts.py` และเทสต์ที่อ่านข้อความจริง เพื่อไม่ให้ประโยคที่ตกลงกันไว้หายไปเงียบๆ ในการแก้ครั้งถัดไป

เมื่อข้อมูลจากเด็คใหม่และการค้นเว็บถูกเติมเข้าระบบแล้ว ช่อง [...] ในตารางจะมีค่าจริง เอกสารนี้จะถูกอัปเดตอีกครั้งพร้อมตัวอย่างคำตอบที่มีตัวเลขจริง
