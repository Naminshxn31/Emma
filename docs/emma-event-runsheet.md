# ใบขั้นตอนทีมงาน วันงาน Embassy World 25–26 พ.ย. 2026 (ชั้น 1)

พิมพ์ติดโต๊ะทีมเทคนิค · ร่าง 19 พ.ย. (20 พ.ย.: เช้าทั้งหมดกดจากหน้าคุม ไม่ต้องใช้คอม — ข้อ 1) — อัปเดตเมื่อซ้อม 23–24 พ.ย. เสร็จ (จุดเดินที่ยังไม่บันทึก, Wi-Fi ที่ใช้จริง, ไมค์)
รายละเอียดของแต่ละเรื่องอยู่ใน `docs/emma-event-host.md`, `docs/emma-ceremony.md`, `docs/emma-event-rehearsal.md`

## 0. กติกาตลอดสองวัน

- **ห้าม deploy / restart เซิร์ฟเวอร์บนหุ่นระหว่าง 25–26 พ.ย.** (4 พ.ย. หุ่นดับเองสองครั้ง ~1 นาทีหลัง deploy/restart)
- **หยุดหุ่นทันที = ปุ่ม E-stop บนตัวหุ่น** (เชื่อได้ที่สุด) · ปุ่มแดงบนมือถือหยุดเดิน+แขน+บทที่พูดอยู่ · ระหว่างหุ่นเดินต้องเปิดหน้าคุมค้างไว้ (หน้าเงียบเกิน 5 วิ = หุ่นหยุดเอง)
- หุ่น มือถือทีมงาน และเครื่องที่เปิดจอใหญ่ **ต้องอยู่ Wi-Fi วงเดียวกัน** (จดชื่อ Wi-Fi ที่ใช้จริงหลังซ้อม: ______________)
- ถอยหุ่นเข้าแท่น/เดินใกล้คน: มีคนกันพื้นที่ด้านหลังหุ่นเสมอ (เลเซอร์ไม่เห็นด้านหลัง)

## 2. ช่วงพิธีเปิด (แอป Emma Ceremony)

1. เปิดแอป **Emma Ceremony** บนหุ่น (หลังบูต แอปที่เปิดเองคือ Emma Event — ต้องเปิด Ceremony เอง)
   - ขึ้นหน้า "เชื่อมต่อ Emma" (ไม่มีรหัส): **ปิดแอปก่อน** (`adb shell am force-stop com.emma.robot.ceremony`) แล้วเปิดใหม่พร้อมรหัสจาก PC —
     การส่งรหัสตอนแอปค้างที่หน้าตั้งค่าไม่มีผล (18 พ.ย.) · ห้ามพิมพ์รหัสให้ใครเห็นบนจอ
2. หน้าคุมพิธีบนมือถือ: กดทีละขั้นตามจังหวะคุณมิกิ (ค่าเริ่ม = กดเอง; ขั้นเดิน/ส่งต่อแตะสองครั้ง)
3. **ระหว่างพิธี Emma ไม่ฟังเสียงในห้อง** (ตั้งใจ — พูดเฉพาะบทที่กด) ยกเว้นช่องตอบสดที่ทีมงานเปิดก่อนคุณมิกิถาม
4. จอใหญ่: ภาพของบทเก่าค้างจนบทถัดไปเข้ามา ไม่มีคลิปคั่น (ถ้ากดหยุดแดง จอค้างที่โลโก้)
   - **ฉาก 8 ไฟ/ม่าน**: ปกติทีมไฟ/ทีมงานทำเอง แล้วทีมงานกดติ๊ก "ไฟล็อบบี้ดับแล้ว" ก่อนกดบท "The lobby lights are off" ·
     ถ้าเปิดให้หุ่นสั่งไว้ จะมีขั้น **"หุ่นสั่งปิดไฟล็อบบี้"** ก่อนขั้นติ๊ก: กด (แตะสองครั้ง) ตอน Emma พูด "…now" → **ดูห้องจริง** → ไฟดับแล้วค่อยติ๊ก →
     แล้วค่อยกดบท "…are off" · หน้าจอขึ้น "ส่งแล้ว (ยังไม่ยืนยัน)" ไม่ได้แปลว่าไฟดับ · ปุ่มหยุดแดงไม่เปิดไฟคืน
5. จบพิธี: ขั้น **ส่งต่อ** → หุ่นเปิดแอป Emma Event เอง → บนหน้าคุม Event กดฉาก **"หลังพิธี"**

## 3. หลังพิธี (แอป Emma Event)

- กดฉากจากหน้าคุม Event ตามลำดับเลข · ฉากที่เดิน: ดูทางว่าง แล้วแตะสองครั้ง
- เดินเข้าทักแขกเอง (`FACE_APPROACH`) ตอนนี้ **ลองแบบไม่หมุนล้อ** (dry run) — จะเปิดจริงหรือไม่ ตัดสินหลังซ้อม
- พักหุ่น: ฉาก **"พัก"** = กลับแท่น (ดูทางหลังหุ่นให้ว่าง)

## 4. เมื่อเกิดปัญหา

| อาการ | ทำ |
|---|---|
| หุ่นดับ/รีบูตเอง (Android) | รอหน้าขึ้น → เข็นหุ่นเข้าแท่น → การ์ดเช้า **"ตั้งตำแหน่งที่แท่น"** (แตะสองครั้ง หุ่นไม่ขยับ) → ถ้าขึ้นว่า "แท่นไม่ได้อยู่ตรงที่บันทึกไว้" กด **"วัดแท่นใหม่"** → พิธีกำลังเดิน: เปิด Emma Ceremony เอง ความคืบหน้าของลำดับยังอยู่ (≤ 3 ชม.) · การเดินที่ค้าง: หน้าคุมขึ้น "interrupted" ให้กดเดินต่อ |
| กดเดินแล้วล้อไม่หมุนเลย | หน้าคุมขึ้น "ล้อหุ่นไม่ขยับเลยตั้งแต่กด … E-stop" = ปุ่มหยุดฉุกเฉินบนตัวหุ่นยังกดค้าง (บอร์ดไม่บอก — 19 พ.ย.) → หมุนคลายปุ่ม แล้วกดใหม่ |
| กด "เดินต่อ" แล้วขึ้น "เพิ่งกดหยุด … ล็อก 60 วินาที" | ตั้งใจ: ทุกการหยุด (รวมปุ่มแดงบนมือถือ) ล็อกแขนและการเดิน 60 วิ → รอแล้วกดใหม่ |
| หุ่นหลุด Wi-Fi ไม่กลับ (19 พ.ย. ไม่กลับเองหลายชั่วโมง) | หน้าคุมขึ้น "ติดต่อหุ่นไม่ได้" ค้าง → ปิด-เปิดหุ่นด้วยปุ่มเครื่อง แล้วทำแถว "หุ่นดับ/รีบูตเอง" |
| เปิด Emma Ceremony แล้วขึ้นหน้า "เชื่อมต่อ Emma" | **ยังต้องใช้คอม** (ผู้ดูแล: ข้อ 2.1) — ตอนซ้อมให้รีบูตหุ่นแล้วเปิด Ceremony หนึ่งครั้งเพื่อยืนยันว่าไม่ขึ้นหน้านี้ |
| Emma ไม่พูดบทที่กด | ดูข้อความใต้ปุ่ม (บทเป็นร่าง/ยังไม่อนุมัติ = กดไม่ได้ — ต้องแก้ก่อนวันงาน ไม่ใช่หน้างาน) |
| Emma เงียบไปราว 1 วิ กลางคำตอบสด | Gemini ตัดสายทุก ~2 นาทีที่ไม่มีใครพูด แล้วต่อเองใน ~1 วิ (บทที่มีเสียงอัดไม่โดน) — รอแล้วถามซ้ำ |
| หุ่นไม่เดิน / หยุดกลางทาง | ของขวาง/คนเดินผ่าน = หยุดถูกแล้ว · Wi-Fi หลุดหรือมือถือล็อกจอ = หุ่นหยุดเอง → เปิดหน้าคุมใหม่แล้วกดซ้ำ |
| เดินไม่ไหวทั้งวัน | เล่นฉากอยู่กับที่ได้: ผู้ดูแลตั้ง `EVENT_WALK_ENABLED=false` (ทำก่อนวันงาน — วันงานห้าม restart) |
| จอใหญ่ไม่ขึ้นภาพ | เครื่องจออยู่ Wi-Fi คนละวงกับหุ่น? · เปิดหน้า `/mirror` ใหม่ |
| ไม่ได้ยินเสียงจากลำโพงห้อง | เช็คเสียงของเครื่องจอ/มิกเซอร์ก่อน แล้วค่อยโทษหุ่น |
| ขั้น "หุ่นสั่งไฟ/ม่าน" ขึ้น **ไม่สำเร็จ** | ไม่มีอะไรถูกส่งไป → กด "ถัดไป" ลองอีกครั้งหนึ่งครั้ง · ยังไม่ได้ → **"ข้ามขั้นนี้"** แล้วให้ทีมไฟ/ทีมงานทำเอง ติ๊กยืนยันตามเดิม |
| ขั้นไฟ/ม่านขึ้น **"ไม่รู้ผล"** | สัญญาณอาจออกไปแล้ว → **ดูห้องก่อน** ห้ามกดซ้ำทันที (รีโมตม่านบางรุ่นกดซ้ำ = หยุดม่าน) · ไม่เปลี่ยน = ทีมทำเอง |
| ส่งแล้วแต่ไฟไม่ดับ/ม่านไม่เปิด | สัญญาณทางเดียว หุ่นไม่รู้ → ทีมทำเอง แล้วค่อยติ๊ก · หลังพิธีเช็คว่ากล่องหันหาตัวรับ/ไม่มีของบัง |
| ไฟค้างดับหลังพิธี | การ์ด "ไฟ/ม่าน" บนหน้าคุมพิธี → "เปิดไฟล็อบบี้" (แตะสองครั้ง) หรือทีมไฟเปิดเอง |

## 5. ต้องเสร็จก่อนวันงาน (เจ้าของ/ผู้ดูแล — `event_preflight.py` เช็คให้)

- เจ้าของฟังเสียงอัดทั้ง 29 บท (`data/ceremony/voice/listen_en.html`) แล้วเซ็น `python scripts/approve_event_script.py --by <ชื่อ> --listened`
- เซ็นไฟล์สไลด์หลังแก้ครั้งสุดท้าย `python scripts/approve_ceremony_slides.py --by <ชื่อ>` (ไฟล์ร่าง = จอใหญ่ไม่ขึ้นหนัง)
- ห้องสาธิต (คิว `s05_l07`) ต้องมีเลขห้องจากทีมขาย หรือตัดขั้นนั้น
- ประโยคเปิดตัวเสียงอัด: อัดใหม่บนแผนเสียเงิน (เทคปัจจุบันจากแผนฟรี = ห้ามใช้เชิงพาณิชย์) หรือให้ Emma พูดเอง
- บันทึกจุดเดิน `stage_centre`, `beside_host`, `beside_globe`, `table_1`–`table_6` ที่หน้างาน แล้วเดินแต่ละจุดสองรอบ + `floor_sim.py preflight --spots`
- deploy รอบสุดท้าย **ภายใน 24 พ.ย.** แล้ว `event_preflight.py --serial` = GO (รอบนี้ต้องมีโค้ดการ์ดเช้า/วัดแท่นใหม่ 20 พ.ย. — ยังไม่เคยขึ้นหุ่น: ลองกด "วัดแท่นใหม่" บนหุ่นจริงตอนซ้อมก่อน)
- จอง IP หุ่นในเราเตอร์ (Netcore 192.168.0.1 → DHCP reservation ของ MAC หุ่น) แล้วพิมพ์ QR ของหน้าคุมทั้งสองหน้า — ไม่ต้องหา IP ด้วย adb ทุกเช้า
- ตอนซ้อม: รีบูตหุ่นหนึ่งครั้ง → เปิด Emma Ceremony ว่าไม่ขึ้นหน้า "เชื่อมต่อ Emma" · กดเดินหนึ่งครั้งตอน E-stop กดค้าง ว่าหน้าคุมขึ้นบรรทัด E-stop
- ตัดสินเดินเข้าทักแบบหมุนล้อจริงหรือไม่ (`FACE_APPROACH_DRY_RUN` ใน robot.env = deploy) ก่อนวันงาน
- **ไฟ/ม่านให้หุ่นสั่ง (ไม่บังคับ — ไม่ทำ = ทีมไฟ/ทีมงานทำเองแบบเดิม)**: ต้องได้คำตอบจากเจ้าของก่อน (อะไรคุมไฟ/ม่าน ยี่ห้อ รีโมตแบบไหน ใครมีแอป/รหัส
  กล่องวางตรงไหนให้อยู่ Wi-Fi เดียวกับหุ่น — `docs/emma-ceremony.md` หัวข้อ "ไฟและม่าน") → ตั้ง adapter + สอนรหัส (`scripts/venue_devices.py`) →
  `VENUE_DEVICES=true` ใน robot.env → deploy + secrets → `event_preflight.py --serial` = GO (มันจะ ping กล่องจากหุ่น) → ซ้อมฉาก 8 บนหุ่นจริงสองรอบ
