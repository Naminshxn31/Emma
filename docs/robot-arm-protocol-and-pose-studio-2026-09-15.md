# โปรโตคอลแขนและสตูดิโอสร้างท่า Emma

วันที่ 15 กันยายน 2026

## ผลที่ยืนยันแล้ว

สร้างท่าใหม่ได้โดยให้ Emma เก็บลำดับคีย์เฟรมเองและส่งเป้าหมายหลายช่องพร้อมกัน วิธีนี้ใช้งานได้โดยไม่ต้องทราบเลขท่าจับมือเดิม และไม่เขียนทับชุดท่า 1–26 ที่อยู่ในบอร์ด

SDK 2.1.2 ที่มากับชุดพัฒนา `开发资料2026.3.16.zip` เปิดเมธอดส่งข้อความดิบของบอร์ดแขน ตัวอย่างผู้ผลิตมีปุ่มเรียกกลุ่ม 1–16, ปุ่มหยุด และกลุ่ม 99 สำหรับกลับท่า แต่ไม่มีตารางเลขช่องกับหัว แขน ข้อมือ หรือนิ้ว จึงต้องสร้างผังจากการสังเกตหุ่นจริง

## คำสั่งที่แกะได้

| คำสั่ง | การทำงานที่ยืนยันจากโค้ด |
| --- | --- |
| `#5P1540T3000\r\n` | สั่งช่อง 5 ไปค่า 1540 ภายใน 3000 ms ค่านี้เป็นเป้าหมายที่ส่ง ไม่ใช่ตำแหน่งที่วัดได้ |
| `#5P1540#7P1500T3000\r\n` | สั่งหลายช่องในคีย์เฟรมเดียว โดยใช้เวลาร่วมกัน |
| `#3GC1\r\n` | เล่นกลุ่ม 3 หนึ่งรอบ |
| `#Read\r\n` | อ่านจำนวนกลุ่ม บอร์ดเครื่องนี้ตอบว่ามี 26 กลุ่ม แต่ไม่ส่งคีย์เฟรมภายในกลับมา |
| `#STOP\r\n` | ขอหยุดจากบอร์ด คำตอบรับไม่รับรองว่ากลไกหยุดจริง |
| `#DOWN\r\n` | เริ่มดาวน์โหลดกลุ่มใหม่เข้า Flash ตาม RIOS |

การวิเคราะห์ RIOS แบบไม่รันไฟล์พบลำดับดาวน์โหลดดังนี้ โปรแกรมตรวจว่ามีอย่างน้อยหนึ่งคีย์เฟรม ส่ง `#DOWN`, รอ handshake ของบอร์ด, ส่งข้อความคีย์เฟรมทีละบรรทัด, ส่ง `#STOP` หลังบรรทัดสุดท้าย และใช้ `#0P500T100` เป็นเฟรมปิดลำดับ จากนั้นบอร์ดตอบ `#DOWN+OK+<หมายเลข>` พร้อมเลขกลุ่มที่สร้างให้เอง

ลำดับตอบรับระหว่างบรรทัดยังไม่ได้ยืนยันกับบอร์ดจริง จึงยังไม่เปิดการเขียน Flash ใน Emma การทดลอง `#DOWN` ก่อนรู้ timeout และ recovery อาจทิ้งบอร์ดไว้กลางโหมดดาวน์โหลด และไม่มีคำสั่งอ่านคีย์เฟรมเดิมเพื่อสำรองก่อนเขียน

## ผังช่องปัจจุบัน

| ช่อง | หลักฐาน |
| ---: | --- |
| 5 | กล้องเคยเห็นการเคลื่อนไหวของแขน แต่ยังไม่ยืนยันด้านหรือข้อต่อ |
| 7 | ภาพก่อนและหลังยืนยันการหันหัว |
| 8 | ภาพก่อนและหลังยืนยันการก้มเงยหัว |
| 1–4, 11 | เคยส่งค่าทดสอบ แต่ภาพเดิมไม่เห็นผลชัด ไม่สรุปว่าไม่มีมอเตอร์ |
| 6, 9–10, 12–20 | ยังไม่ทดสอบและยังไม่จับคู่กับส่วนจริง |

ข้อมูลแบบอ่านด้วยโปรแกรมอยู่ใน `docs/robot-interface-reference/servo-channel-map.json` ไม่มีช่องใดถูกตั้งชื่อเป็นนิ้วจนกว่าจะเห็นการเคลื่อนไหวจริง

## สตูดิโอท่าใน Xbox Direct

หน้าเดียวกับจอยมีส่วน **สร้างท่าใหม่ใน Emma**:

1. กด X เพื่อเชื่อมแขน การเชื่อมไม่ส่งท่า
2. เลือกช่องและค่า แล้วกด **ส่งค่าช่องนี้ช้า 3 วินาที**
3. เมื่อค่าหลายช่องได้ท่าที่ต้องการ กด **จำคีย์เฟรม**
4. ปรับช่องต่อไปแล้วจำคีย์เฟรมเพิ่ม
5. กด **เล่นร่างท่า** เพื่อเล่นลำดับทั้งหมด หรือกด B เพื่อยกเลิกและล็อก

ร่างท่าเก็บเป็น JSON ในพื้นที่ของแอปบน Android และกลับมาใช้ได้หลังเปิดแอปใหม่ แต่ละคีย์เฟรมเก็บเฉพาะช่องที่เคยส่งจริง ไม่เติม 1500 ให้ช่องที่ไม่รู้จักอัตโนมัติ การกด **ล้างร่าง** ยกเลิกการเล่นก่อนลบข้อมูล

## สิ่งที่ต้องทำเพื่อให้ผังครบ

ต้องวางกล้องให้เห็นหัว แขน และมือ แล้วทดสอบทีละช่องด้วยระยะเปลี่ยนเล็กและเวลาช้า บันทึกส่วนที่ขยับ ทิศทางเมื่อเพิ่มค่า และช่วงที่ไม่ชน การอ่าน serial อย่างเดียวไม่บอกชื่อข้อต่อหรือมุมจริง เพราะบอร์ดนี้ไม่มีตำแหน่งย้อนกลับที่ยืนยันแล้ว

กลุ่ม 1–26 สามารถเรียกดูการเคลื่อนไหวทีละกลุ่มและตั้งชื่อจากภาพได้ แต่ไม่สามารถแยกคีย์เฟรมภายในกลุ่มด้วย `#Read` การสร้างท่าใหม่ใน Emma จึงเป็นเส้นทางที่ตรวจสอบและย้อนกลับได้มากที่สุดในตอนนี้

## การตรวจ

- ทดสอบเฉพาะ Xbox Direct ผ่าน 15 รายการ
- Android assembleDebug และ lintDebug ผ่าน
- ติดตั้ง APK บนหุ่นแล้ว เปิดแอปในสถานะฐานล้อไม่เปิดควบคุมและแขนยังไม่เชื่อม
- UI บนหุ่นแสดงสตูดิโอท่า ร่างเริ่มต้น 0 คีย์เฟรม และหลักฐานช่อง 5
- log ตอนเปิดมีเฉพาะการปิด Aobo และเชื่อม Navigation SDK ไม่มีคำสั่งแขนหรือคำสั่งเคลื่อนที่
