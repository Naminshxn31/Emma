3. Voice Pipeline

[standby]  browser mic (AEC/NS/AGC + compressor MIC_BOOST) ──PCM16 16k──▶ /ws/wake
             └▶ wake.WakeStream.feed → sherpa KWS (EMMA×0.5 / IMMA×1.0 / "A MA"×0.8 ของ WAKE_THRESHOLD)
             └▶ hit → {"type":"wake"} → browser ปิด /ws/wake, เปิด /ws   (wav ถูกเขียนถ้า WAKE_DEBUG/ENROLL)
[call]     browser mic (CALL_MIC_BOOST) ──PCM16──▶ /ws → VoiceSession._browser_to_provider
             └▶ summoned? ears closed ≤10 s จนกว่า greeting ถูกได้ยิน (working tree)
             └▶ provider.send_audio → VadGate.feed (Silero; pre-roll; VAD_MIN_RMS floor; grace 3 s; stand_down)
                  └▶ activity_start / audio / activity_end → Gemini Live
           Gemini ──audio 24k + transcripts + tool calls──▶ _provider_to_browser
             └▶ audio → browser (display.set_audio_lead จาก "played")
             └▶ heard.record(transcript)  → turnlog "heard"
             └▶ tool_call → registry.dispatch_all (ตามลำดับ; timeout 15 s / 30 s paced)
             └▶ go_away → _reconnect ด้วย resume handle → ProviderEvent("resumed")
[self-speech] events.announce() ← tour nudge / follow_canva / robot_arrived / reminder / face
             └▶ wait_until_heard → still_relevant → send_text  (lock เดียว)

HALF_DUPLEX (เปิดใน .env เจ้าของ): เบราว์เซอร์ไม่ส่งไมค์ขณะ playing (index.html:1972) — คือจุดที่คำสั่ง "หยุด" ระหว่างหุ่นพูดไม่มีวันถึงเซิร์ฟเวอร์

  camera.open_camera(FACE_CAMERA | -1=ค้นหาตัวที่ภาพขยับ)  →  cap.read ที่ FACE_FPS=5
  → asyncio.to_thread(watcher.see, frame)
       faces.locate(frame)            SCRFD det 640 — ทุกหน้าในเฟรม เรียงใหญ่→เล็ก

5. Face Recognition Pipeline

enrol:  enroll_app.py / enroll_face.py → enrollment.usable_face (≥110 px, หน้าเดียวเด่น ≥4×)
        → 5 ท่า (front/side/side/far/front2) → review(): shots_agree ≥0.45, check_against_gallery
        → save_shots: JPG crop (+45% margin) → data/faces/enrolled/<ชื่อ>/*.jpg     ← ภาพดิบถาวร
build:  build_face_gallery.py: staff.csv(สตูดิโอ) + enrolled/ [+ --with-brokers opt-in]
        → Gallery.save → gallery.npz {names, vecs, meta{group}, model_tag}            ← ไม่มี consent
match:  facewatch.see: gallery.match(vec) → (best_i, cosine)
        score ≥ 0.50 → name  |  ≥0.42 → presence เท่านั้น  |  else stranger
        stranger vec เทียบกับ _strangers[≤16] ใน RAM (กันทักซ้ำ, หมดอายุตาม cooldown 600 s)
        streak: known ต้อง 3 เฟรม, stranger 6 เฟรม → Sighting

6. Robot Command Flow

Gemini tool call go_to_place(place)
  → registry.dispatch (timeout 15 s; drop unknown args)
  → robot.go_to_place: robot_link.find_place(place)   [ทุกคำในชื่อ POI ต้องอยู่ในคำขอ; ไม่ match → ถามกลับ]
  → robot_link.send("move_to_point", place=…)
       ROBOT_ENABLED false → "mock"
       session._active None หรือ STATE.connected False → "mock"
       else live._send_json({"type":"robot","action":…,"args":…})  → "ok"   (fire-and-forget)
  ← {"ok", "hardware", "instruction"}   STATE.moving=True (สิ่งที่ส่ง ไม่ใช่วัด)
robot app (ยังไม่มี) → SDK moveToPoint → callback → {"type":"robot_arrived","place","ok"} ขึ้น /ws
  → session._browser_to_provider → robot_link.arrived → events.announce("ถึงแล้ว…")
robot app → {"type":"robot_ready","places":[…]} → robot_link.app_connected  ← ใครส่งก็ได้บน /ws

คำสั่งที่มี: move_to_point cancel_navigation go_home — ระดับสูงทั้งหมด ไม่มีความเร็ว/พิกัดดิบ/แขนกล ✓ · ชั้นที่ไม่มี: permission, safety policy, allow-list POI, battery/state check ที่วัดจริง, timeout รอ arrived, device identity

12. Offline Mode และ Fallback

  • ทำงานได้โดยไม่มีเน็ต: wake word, VAD, face detect/ID, local TTS ของสถานีลงทะเบียน, BM25 search, IR — ทั้งหมดในเครื่อง ✓
  • ไม่ทำงานเมื่อไม่มีเน็ต: ทุกอย่างที่ลูกค้าได้ยิน — ไม่มีประโยคเดียวที่หุ่นพูดได้เองในเครื่อง (app/voice.py มี TTS ไทยแต่ใช้แค่กับสถานีลงทะเบียน)
  • Fallback ที่มี: GEMINI_MODEL_FALLBACK (โมเดลถอน), lexical เมื่อ embed ล้ม, mock เมื่อ hardware ไม่มี, sample units ปิดเมื่อ DB ล่ม (ถูกต้อง)
  • เบราว์เซอร์: /ws reconnect เมื่อ token ผิดหยุดถาวรพร้อมเหตุผล ✓; เมื่อเน็ตหลุดกลางสาย → goToSleep() → รอ wake — ลูกค้าไม่รู้ว่าเกิดอะไร

สรุป: ไม่มี offline mode ตามนิยามของ brief (คำสั่งฉุกเฉิน, เรียกพนักงาน, บอกว่าเน็ตหลุด) — README ยอมรับข้อนี้ตรงๆ
