# Emma Event — Emma เป็นเจ้าบ้านในวันงานอีเวนต์

เจ้าของ 30 ต.ค. 2026: *"ทำโหมดใหม่ แยกเป็นอีกแอป ... ให้ emma เป็น host งานคอยรับแขกในวันงานอีเว้น
... เชิญลูกค้า แล้วพาไปยังจุดต่างๆ และคอยไปทักทายคนต่างๆที่โต๊ะ ... ทำเป็นซีนๆ"*
· สถานที่: สำนักงานชั้น 1 · ทีมงานกดเปลี่ยนซีน · วันงาน 25–26 พ.ย. 2026
· แผนซ้อมก่อนงาน + ตารางแก้ปัญหาหน้างาน: [emma-event-rehearsal.md](emma-event-rehearsal.md)

> ร่างแรก — บทของแต่ละฉากยังเป็นร่างของผม เจ้าของยังไม่ได้บอกว่าแต่ละฉากต้องทำ/พูดอะไร
> **สถานะ 19 พ.ย.:** robot.env เปิด `EVENT_WALK_ENABLED=true` แล้ว และ `FACE_APPROACH`/`FACE_APPROACH_ANYONE=true` แต่ **`FACE_APPROACH_DRY_RUN=true`** (เดินเข้าทักยังไม่หมุนล้อ) ·
> เส้น `event_rehearsal` เดินบนหุ่นจริงแล้ว 3 รอบ (16 พ.ย.) — จุดของพิธี/โต๊ะยังไม่ได้บันทึก · ใบขั้นตอนวันงาน: [emma-event-runsheet.md](emma-event-runsheet.md) ·
> เช็คความพร้อมทุกเช้า: `python scripts/event_preflight.py --serial <IP>:5555`

และสามแอปเปิดพร้อมกันไม่ได้ (ไมค์/แขนใช้ได้ทีละแอป) แอปที่เปิดทีหลังจะปิดอีกสองแอปให้ก่อนใช้แขน · หลังบูตหุ่นเปิดแอปนี้เอง

## พิธีเปิดอยู่ในแอปของตัวเอง

เจ้าของ 9 พ.ย.: *"อันนี้ทำแยกกับอันเดิมนะ ไม่งั้นจะปนกัน"* — พิธีเปิด (บทของคุณมิกิ ลำดับพิธี คิว ช่องตอบสด) ย้ายไปแอป **Emma Ceremony**: [emma-ceremony.md](emma-ceremony.md) ·
แอปนี้ (Emma Event) เหลือแค่ฉากงาน: รับแขก พาแขก ทักตามโต๊ะ และช่วงหลังพิธี · ไม่มีฉากพิธีในไฟล์งานแล้ว

**ใช้ร่วมกับแอปพิธี:** จุดเดินและแผนที่ชั้น 1, คลิปและจอใหญ่ (`clips` ในไฟล์งาน), แขกที่ลงทะเบียนหน้า ·
**ระหว่างที่แอป Emma Ceremony เปิดอยู่บนหุ่น** หน้าคุมนี้ขึ้นแถบบอก และฉาก/เดิน/คลิป/เดินเข้าทักกดไม่ได้ (ปุ่มหยุดแดง หยุดคลิป บันทึกจุด ยังใช้ได้) ·
จบพิธี แอปพิธีเปิดแอปนี้ให้ แล้วกดฉาก **"หลังพิธี"** (ปิดจอใหญ่ เดินเข้าทักแขกที่จำได้)

**คลิป:** วางไฟล์ที่ `data/events/clips/` (gitignore) ตามชื่อใน `clips` ของไฟล์งาน แล้ว `robot_server.py deploy` ส่งให้ · ตอนจอใหญ่เปิด หน้าจอโหลดคลิปทั้งไฟล์มาเก็บก่อน (หน้าคุมบอก "พร้อมบนจอแล้ว") เพื่อไม่ให้ Wi-Fi สะดุดกลางคลิป ·
สั่งเล่นจากฉากที่ติด `clip` หรือปุ่มบนหน้าคุม (แขกในงานสั่งด้วยเสียงไม่ได้) · ระหว่างคลิปเธอเงียบ จบแล้วพูด `after_th` · จอไม่ตอบ = หน้าคุมบอกว่าเล่นไม่สำเร็จ และ Emma ไม่อ้างว่าเล่นแล้ว

**"เปิดทีวี" คือเอาหน้า Emma ขึ้นจอผ่านเครื่องของห้องนั้น** (`tv` ของฉาก) ซอฟต์แวร์เปิดหน้าต่างและปลุกจอของคอมได้ แต่ไฟของตัวทีวีและเสียงออกลำโพงไหนต้องตั้งที่เครื่องนั้นก่อน

## เปิดใช้วันงาน

ค่าเหล่านี้อยู่ใน `data/robot-server/robot.env` แล้ว (19 พ.ย.: การเดินและเดินเข้าทักเปิด แต่เดินเข้าทักยังเป็น `FACE_APPROACH_DRY_RUN=true` จนซ้อมผ่าน — [แผนซ้อม](emma-event-rehearsal.md)):

```
FACE_GUESTS_FILE=data/faces/guests.npz
GUEST_SYNC_PORT=8004
FACE_APPROACH=true             # เดินเข้าทักแขกที่จำได้ (ทีละขั้นตาม emma-face-approach.md)
FACE_APPROACH_ANYONE=true      # เห็นคนยืนแล้วเดินเข้าทักทุกคน ชื่อตัดสินที่จุดหยุด (ข้อ 9 ของไฟล์เดียวกัน)
EVENT_WALK_ENABLED=true
```

## ฟังคนใกล้

เจ้าของ 5 พ.ย. เย็น: *"เอาฟังเสียงคนเดียวออก แล้วพยายามให้หุ่นฟังเสียงคนใกล้ คนไกลออก"* · ลงเสียงจากเมนูและปุ่มฟังคนเดียวเอาออกทั้งหมดแล้ว (บนหุ่นจริง: ไม่เคยกันเสียงคนอื่นสักครั้ง และทิ้งคำสั้นของเจ้าของเสียง 11 ครั้ง) · ประตูคนใกล้จากไลดาร์ตั้ง `shadow` ไว้เก็บตัวเลข ยังไม่กันอะไรจริง: [วิธีวัดและตัวเลือกอื่น](near-voice-bench.md) · **ในงานที่คนเยอะ คนดำเนินพิธีควรถือไมค์** ประตูนี้รู้ว่ามีคนใกล้ ไม่รู้ว่าใครพูด

## เดินวนเองและกลับแท่นเอง

เจ้าของ 5 พ.ย.: *"เราปล่อยให้หุ่นเดินทั่วๆเองได้ไหม หรือให้กลับแท่นเองตามสถานการณ์"* · ฉาก **เดินวนทักแขกทั่วล็อบบี้** (`roam` ในไฟล์งาน) · เดินเฉพาะจุดในรายการ ไม่สุ่ม เพราะเลเซอร์ไม่เห็นของเตี้ย และแผนที่ไม่มีโต๊ะ · **จุด `lobby_west/mid/east` เลือกจากผังและรอบสำรวจ ยังไม่เคยเดินเป็นจุดหมาย ต้องเดินตรวจตอนซ้อม (R11c) และตรวจใหม่หลังจัดโต๊ะ** ·

| เมื่อ | หุ่นทำอะไร |
|---|---|
| ปกติ | แวะยืนจุดละ 45 วินาที แล้วไปจุดถัดไป |
| แขกคุยอยู่ หรือเธอพูดอยู่ | รอจนจบ + 30 วินาที |
| เจอแขกจากตู้สแกน | เดินเข้าไปทัก แล้วค่อยเดินต่อ |
| แบตต่ำกว่า 30% | บอกแขกว่าขอตัว กลับแท่น ชาร์จถึง 70% แล้วออกเอง (ค่าเดา รอวัด) |
| ไม่มีคนแถวนั้น 10 นาที | กลับแท่นเงียบๆ มีคนมาแล้วออกเอง |
| กดหยุด, พูดว่าหยุด, ปิดหน้าคุม, แอปหลุด, รีสตาร์ต | เลิกเดินวน **ต้องกดฉากใหม่** |
| เดินไม่ถึงติดกันสองครั้ง | เลิกเดินวน หน้าคุมบอกเหตุ |

**ยังต้องมีคนถือหน้าคุมเปิดค้าง และมีคนอยู่ใกล้ E-stop** ไม่ใช่ปล่อยทิ้งโดยไม่มีคนดู

## หน้าคุมมือถือคืออะไร

เปิด `http://<ip หุ่น>:8003/event-control?key=...` บนมือถือทีมงานในวง Wi-Fi เดียวกับหุ่น แล้วกดฉากจากรายการ · หุ่นทำตามฉาก (เดิน เปิดจอ เล่นคลิป พูด) ·
ปุ่มแดงด้านล่างคือหยุด (การเดิน แขน และบทที่กำลังพูด) · หน้านี้เป็นสายจูงด้วย: ปิดหน้าหรือล็อกจอ หุ่นหยุดใน 5 วินาที

**การ์ด "สั่งเอง ทีละอย่าง"** (เจ้าของ 14 พ.ย. "ทำหน้าปุ่มกดยัง ทำแบบ manual") ใต้ช่องฉาก — ช่องฉากทำทุกอย่างพร้อมกัน การ์ดนี้ทำทีละอย่าง:

- **พูด** ประโยคของฉากตรงที่หุ่นยืน (`POST /event/say {scene}`) แตะครั้งเดียว ไม่เดิน ไม่สั่งท่า (แขนยังขยับตามจังหวะพูดได้ — SPEECH_GESTURES) ฉากปัจจุบันไม่เปลี่ยน ·
  ใต้ปุ่มบอกว่าจะพูดอะไร (`manual_preview`: ประโยคใน «» ตามตัว หรือ "Emma จะ…" ตามคำสั่งในไฟล์งาน — ตัวเลือกเดียวกับที่การกดใช้ `_manual_choice`) ·
  ประโยค "ถึงแล้ว" เฉพาะเมื่อการเดินล่าสุดถึงจุดของฉากนั้นจริง**และฐานไม่ถูกเห็นว่าขยับหลังถึง** (`walk_frames.moved_at` — ถูกเข็น/จอย/เข้าแท่นด้วยมือ = ประโยคตรงที่ยืน;
  WALK_FRAMES ปิด = เชื่อการเดิน) (ปุ่มติดป้าย "ประโยคตอนถึง") · ฉากเปิดตัวเล่นเสียงอัด · ฉากที่ไม่มีประโยคตรงที่ยืนไม่มีปุ่ม ·
  กดระหว่างหุ่นเดินไม่ได้ · หุ่นออกเดินหรือที่ยืนเปลี่ยนก่อนถึงคิวพูด = ยกเลิก
- **ท่าทาง** (`POST /event/body {action}`) โบกมือ โบกมือทักทาย ยื่นมือจับมือ ยกแขนขวา/ซ้าย เอาแขนลง + ท่านางงามและ "เอามือลง" · แตะครั้งเดียว ·
  ด่านแขนเดิมทุกด่าน (สวิตช์ ล็อกหลังหยุด ระหว่างเดินไม่ขยับ) · ไม่มีท่าหัว · ไม่มีสายเปิด = กดกระดิ่งเรียกสายก่อน (ไมค์ที่ปิดค้างยังปิด) แล้วเช็คหยุดแดง/แอปพิธีซ้ำ ·
  ท่าที่หุ่นทำไม่ได้ตอนนี้แสดงเทาพร้อมเหตุผล (รายการคงที่; ท่านางงามด้วย — `_manual_pageant_why`; ล็อก 60 วิของแอปหลังกดหยุด = เทาทุกท่า) ·
  **ขอครั้งเดียว ไม่ลองซ้ำ** (`_gesture(retry=False)`: กดซ้ำระหว่างท่าก่อนยังเล่น = "แขนกำลังทำท่าอยู่" ไม่ต่อคิวเป็นท่าที่สอง) · ระหว่างหุ่นเดินปฏิเสธก่อนแตะอะไร ·
  ท่านางงามยกอยู่แล้ว = บอกว่ายกอยู่แล้ว ไม่ขอซ้ำ (กำลังลง = ขอใหม่) ·
  **"เอามือลง (ท่านางงาม)"** รอจนหุ่นบอกว่าไม่มีท่าค้าง ยกเลิกท่านางงามที่กำลังขอ **และเอาท่าที่การกดฉากนั้นยังรอทำคืนมา** (`MANUAL["down_seq"]`/`_arm_free`:
  มือก่อนประโยคเปิดตัว มือตอนเดินและที่จุด ท่าสำรองหลังประโยค — กดฉากใหม่ = มือของการกดใหม่) · ไม่มีท่านางงามยกอยู่ = บอกว่าไม่ได้ส่งอะไร (แขนท่าอื่นใช้ "เอาแขนลง/ท่าพัก") ·
  แอปพิธีอยู่บนหุ่น = ทุกปุ่มเทา ยกเว้นเอามือลง · การ์ดอ่านไม่ได้ = ซ่อนการ์ด ไม่ทำให้ /event/state ล่ม
- **เดินไปจุด** ที่บันทึกแล้ว (`/event/go`) แตะสองครั้ง ไม่พูด · ทุกปุ่มแตะสองครั้งของหน้านี้ แตะรัวเร็วกว่า 0.4 วิไม่นับ
- แอป Emma Ceremony อยู่บนหุ่น = ทุกปุ่มถูกปฏิเสธ ยกเว้น "เอามือลง"

## ห้องมัลติมีเดีย

เจ้าของ 5 พ.ย.: *"เปิดค้าง แต่เราไม่เข้าทำเป็นปิดเลย"* วันงานเปิดประตูค้างให้แขก แต่หุ่นไม่เข้า ·
ไม่มีจุดหรือขั้นไหนของงานเลยแนวประตู (มีเทสต์) · แผนที่ต้องคงเป็นประตูปิด: ตอน `map_check` ประตูที่เปิดอยู่จะขึ้นเป็น phantom ให้ใส่เลขนั้นใน `--keep` ·
มาร์คพื้นที่เดินเข้าทักแขก (`บันทึกมุมพื้นที่ตรงนี้`) ห้ามเลยประตู · จอของห้องนั้นสั่งจากข้างนอกได้ หุ่นไม่ต้องเข้าไป

## ของบนพื้นที่เลเซอร์ไม่เห็น

เจ้าของ 5 พ.ย. (มีรูป): ข้างกองลูกโป่ง ล้อโดนของบนพื้นทั้งสองรอบสำรวจ ตรงกับข้อมูลรอบเดินที่ (−7.85, 0.80) · ลงไว้ใน `floor_hazards` ของไฟล์งาน ·
เจ้าของ 5 พ.ย.: เอาออกไม่ได้ *"ให้หุ่นเดินหลบตรงนั้นพอ"* · จุด "ฝั่งทางเข้า" ย้ายออกมาแล้ว · ทุกการเดินของงานเช็คจากตำแหน่งจริงตอนออกเดิน ถ้าเส้นตรงจะตัดผ่านก็แทรกจุดอ้อม (`keep_off_hazards`) · บันทึกจุดในรัศมีไม่ได้ · เดินเข้าทักแขกไม่ตัดผ่าน ·
**บอร์ดยังไม่รู้จักจุดนี้จนกว่าจะอัปแผนที่ที่ใส่ `--block`** ระหว่างทางบอร์ดอาจเลี่ยงเองออกนอกเส้นตรงเมื่อเจอคน ถ้าสำคัญให้อัปหลังรอบสำรวจ 16 พ.ย.

## ปุ่มเดินเปิดตัว · ท่านางงาม (9 พ.ย. 2026 — เล่นยืนที่แท่นแล้ว 10 พ.ย., ยังไม่เคยเล่นตอนเดิน)

เจ้าของ: *"ขอปุ่มกดท่าเปิดตัวหุ่น ขอเป็นท่านางงามเลยได้ไหม ที่เดินแล้วหันหน้าโบกมือไปมา"* → เลือก **"โบกไปด้วยระหว่างเดิน"**
และ *"ท่านี้จะใช้เฉพาะโหมดนี้แก้กฏได้ เพราะถ้าจบงานก็กลับไปโหมดเดิม"*

การ์ดใหญ่บนสุดของหน้าคุม (แตะสองครั้ง):
1. เดินไปกลางเวที (เปิดการเดินและบันทึกจุดแล้ว) — พอล้อออกตัว **แขนขวากางออกข้าง ท่อนแขนตั้ง ฝ่ามือหันออก แล้วโบก หัวหันซ้ายทีขวาที** (ท่าปัจจุบัน 10 พ.ย. — ดูรอบสามข้างล่าง)
2. **พูดระหว่างเดิน** (`say_on_walk`, เจ้าของ 10 พ.ย. *"รวมทั้งหมดเป็นปุ่มเปิดตัว โดยให้หุ่นเดินไปด้านหน้าพร้อมโบกมือและพูด"*): พอล้อออกตัวและมือขึ้น Emma พูด «Hello everyone! I'm Emmaaa! …» (อังกฤษเสมอ น้ำเสียงนางงาม) **ด้วยเสียงอัด Jessica** (ข้างล่าง) ขณะเดินและโบก · ถึงแล้วไม่พูดซ้ำ · พูดจบและเดินถึงแล้ว ~1 วิ มือลงช้าๆ (3 วิ) แล้วกลุ่ม 99 · มือถูกปฏิเสธตอนออกตัว = ไม่ลองยกอีกระหว่างล้อหมุน (พูดอย่างเดียว) · ฉากอื่นที่ไม่มี `say_on_walk` ยังพูดตอนถึงแบบเดิม
- **ตั้งแต่ 23 พ.ย. หุ่นเริ่มในกล่อง — เดินออกมาก่อน แล้วค่อยยกมือ** (เจ้าของ *"แล้วก็หุ่นอยู่ในกล่องอาจจะต้องให้หุ่นเดินออกมาก่อน จึงค่อยยกมือนะ"*; ฉาก debut `walk_out_of_box`, ชนะ `say_on_walk` ข้างบน — ทั้งตอนเปิดการ์ดต่อเนื่องและไม่เปิด; ยังไม่เคยเล่นบนหุ่น):
  0. **เดินออกได้ครั้งเดียว ต้องมีคนบอกว่าหุ่นอยู่ในกล่อง (`app/event_box.py`, รีวิวรอบสอง 23 พ.ย.)** — ปุ่ม "หุ่นอยู่ในกล่องแล้ว" (แตะสองครั้ง) ในกล่องสถานะบนหน้าคุม
     (พิธี: ติ๊ก "ไฟห้องปิด ม่านปิด หุ่นพร้อมในกล่อง" ที่มี `in_box`) = **พร้อมเดินออกครั้งเดียว และล็อกแขนตั้งแต่ตอนนั้น** · ยังไม่กด = การ์ด 1 ถูกปฏิเสธ
     · การกดการ์ดใช้สิทธิ์ทันที (จดลงไฟล์) **ได้คืนเฉพาะเมื่อไม่มีตัวเดินออกตัวเลย** (ถูกปฏิเสธ/หยุดก่อนล้อหมุน/การเดินปิด) — ออกเดินแล้วถูกตัด, ตำแหน่งกระโดด
     (`line_lost` = ไม่รู้ระยะ ไม่ใช่ 0 ม.), ตัวเดินถูก kill, เซิร์ฟเวอร์เริ่มใหม่กลางทาง, ออกครบแต่ไม่เห็นล้อนิ่ง, ออกครบแล้ว = **ใช้ไปแล้ว** กดซ้ำไม่ได้
     ("หุ่นออกจากกล่องไปแล้ว / ไม่แน่ใจว่าออกไปแล้ว — ถ้าหุ่นกลับเข้ากล่องแล้ว กด 'หุ่นอยู่ในกล่องแล้ว' ก่อน") · เริ่มลำดับพิธีใหม่ไม่ได้คืนสิทธิ์

     (ปลดแล้ว = ไม่มีสิทธิ์เดินออก ทำต่อด้วยปุ่มทำเอง: โบก+พูด, ไปเคาน์เตอร์ จับมือ แขก 1–3 กลับเคาน์เตอร์ — แตะสองครั้ง ทั้งสองหน้า)
     · จำข้ามการรีสตาร์ต (`data/events/.run/box.json`; อ่านไม่ได้ = อยู่ในกล่อง ไม่มีสิทธิ์) · **ล้างเองตอน MIC_HOLD_RESET_HOUR เช้าวันถัดไป** (แบบปิดไมค์ค้าง)

     MoveTo ของบอร์ดจากในกล่อง: รีวิว 23 พ.ย.) · ไม่มีท่านางงามระหว่างเดิน ไม่มีด่านข้างขวา (`right_clear_m`: แขนไม่ได้กาง และผนังกล่องข้างตัวจะทำให้หยุดรอตลอด)
     · **ครบหรือไม่ออก**: ขั้น forward ของเดินออกมี `short_ok: false` — "เหลือไม่ถึง 0.2 ม. ถือว่าถึง" ของ board_walk ไม่ใช้ และเซิร์ฟเวอร์วัดระยะเองอีกชั้น (ขาดเกิน 3 ซม. = ไม่ออก)

  · **หมุนเกิน 150° = สองครั้งครึ่งละครึ่ง ทางเดียวกัน** (`TURN_SPLIT_DEG`, ตัวจำลอง 23 พ.ย.: ที่ ~180° ทางที่สั้นกว่าพลิกไปมาตามสัญญาณรบกวนของตำแหน่ง
  เพียงเศษองศา การหมุนของ board_walk หยุดทุกครั้งที่พลิก แล้วหมดเวลา 20 วิ — ส่วนต้อนรับ→หน้าห้องมัลติมีเดีย 5 ใน 20) รวมการหมุนของจุดเอง (การ์ด 3 หันหลังให้เคาน์เตอร์)
  · การ์ดบอกว่าจะหมุนที่ไหน คิดจากจุดที่บันทึก (ท่อนจากจุดจบเปิดตัวไปเคาน์เตอร์รู้ตอนกดเท่านั้น)
- **จุดแขกจุดไหนยังไม่มีตำแหน่ง (หรือไม่มีทิศ) = ไม่ไปหาแขกเลย** จับมือคุณมิกิแล้วยืนรอที่หน้าเคาน์เตอร์ · ไม่มีจุดเคาน์เตอร์ = เปิดตัวอย่างเดียว · การ์ดบอกก่อนกด
- **เซิร์ฟเวอร์ไม่สั่งหันหัวตั้งแต่กดจนจบ (การ์ดเขียน "หัวไม่หันตามคน ไม่ก้มหา" ไม่ใช่ "นิ่ง"):** head_follow ไม่ส่งหัวเลย (หันตามหน้า ก้มหาเสียง หันหาเลเซอร์ สแกนตอนเดิน คำใบ้ของเดินเข้าทัก) · กล้องไม่ทัก
  (ท่าจับมือของคำทักคือกลุ่ม 6 ที่ขยับหัวด้วย) · ท่าประกอบคำพูดไม่ขยับแขน · ท่า/จับมือที่สั่งด้วยเสียงถูกปฏิเสธ busy (หยุดไม่เคยถูกปฏิเสธ)
  · ปุ่มท่าทางของการ์ด "สั่งเอง" เทา (เอามือลงยังกดได้) · เปิดเดินเข้าทักไม่ได้ระหว่างการ์ด · ท่านางงามตอนเปิดตัวยังหันหัวเองตามที่ซ้อม (ของแอป)
  · **ที่ server กันไม่ได้:** ท่านางงามตอนเปิดตัว และกลุ่ม 6 ของผู้ผลิต (ท่าจับมือ) / การพักแขนขยับหัวเอง (`BodyController`: "the group moves the head too")
- **จบทั้งการ์ด ไม่ทำต่อเอง** เมื่อ: หยุดแดง · พูดว่าหยุด · หยุดจากหน้าคุมหุ่น · หน้าคุมเงียบ 5 วิ · หน้าหุ่นหลุด 3 วิ · ปุ่ม B · แอปพิธีเปิด ·
  กดฉาก/จุด/กลับแท่นอื่น · มีการเดินอื่น · เดินไม่ถึง/ไม่ออกเดิน · **ล้อไม่ขยับเลย 15 วิหลังเริ่มท่อน** (`WHEELS_STILL_END_S`, รีวิว 23 พ.ย.: 8 วิ จบการ์ดเพราะแขกยืนตรงหน้าตอนท่อนเริ่ม — บอร์ดแยกแขกกับ E-stop ไม่ได้ ทั้งคู่คือ MoveTo ถูกถือไว้ ล้อนิ่ง; ปลด E-stop ภายใน 15 วิ หุ่นเดินต่อเอง · บอร์ดไม่บอก E-stop: กด E-stop ตอนจับมือแล้วปล่อยใน 45 วิ
  เคยเดินต่อไปแขกคนถัดไปเอง — กด E-stop แล้วให้กดหยุดแดงด้วย) · **กดเอามือลง** · ท่าจับมือถูกปฏิเสธ/ล้มเหลว/ถูกหยุด/ไม่บอกเริ่มใน 8 วิ/ไม่บอกจบใน 60 วิ ·
  เซิร์ฟเวอร์เริ่มใหม่ (การ์ดบอกว่าถูกตัดที่ขั้นไหน) — การ์ดบอกเหตุ ขั้นที่หยุด และสิ่งที่เหลือให้ทำเองด้วยการ์ด "สั่งเอง ทีละอย่าง" (ไปจุด / ยื่นมือจับมือ)
  · "เดินต่อ" ของการ์ดการเดิน = เดินต่อเฉพาะท่อนนั้นไปจุดของมัน ไม่ทำการ์ดต่อ
- **กดการ์ด 1 ซ้ำระหว่างทำต่อเนื่องไม่ได้** (จะเดินตรงไปอีก 1 ม. จากตรงที่ยืน — หน้าแขกหรือหน้าโต๊ะ) กดหยุดแดงก่อน
- ตัวจำลอง: `scripts/floor_sim.py` `tour_sequences` (ในก่อนขึ้นหุ่น `preflight` และ `event-day`) — จุดแขก**สมมติ** (แถวห่างเคาน์เตอร์ 1.9 ม. ห่างกัน 0.8 ม.
  แขกยืนหน้าหุ่น 0.65 ม.) จนกว่าจะมาร์ก (`--spots`) หรือบันทึกที่หุ่น · ภาพ `.tmp/floor1-sim/event_sequence_20261121_card1_tour.png`

## ทางหยุด (ทุกทางทำงานพร้อมกัน)

1. ปุ่ม **E-stop บนตัวหุ่น** — ทางที่เชื่อได้ที่สุด
2. ปุ่ม **หยุด** สีแดงด้านล่างหน้าคุม
3. แขก/ทีมงานพูด "หยุด" กับ Emma (ในแอป Emma Ceremony: ได้ยินเฉพาะตอนหุ่นเดินหรือทำท่า)
4. **หน้าคุมขาดการติดต่อเกิน 5 วินาที → หุ่นหยุดเอง** (ล็อกจอ ปิดหน้า Wi-Fi หลุด) —
   ระหว่างหุ่นเดินต้องเปิดหน้าคุมค้างไว้
5. แอป Emma Event บนหุ่นปิด/หลุดเกิน 3 วินาที → หุ่นหยุดเอง
6. กดหยุดจากหน้าคุมหุ่นบน PC (`/mapview`)

## เตรียมก่อนวันงาน (ต้องทำที่สถานที่จริง)

1. **จัดโต๊ะให้เสร็จก่อน แล้วค่อยทำแผนที่ชั้น 1 ใหม่** — หุ่นวางทางจากแผนที่ ถ้าย้ายโต๊ะหลังทำแผนที่
   หุ่นจะเดินตามแผนที่เก่า (และห้าม `--map` ตอนมีคนในห้อง — คนกับบานประตูถูกบันทึกค้าง เกิดแล้ว 28 ต.ค.)
   · **ทางที่ไม่ต้องเคลียร์ห้อง:** เดินเส้นทางงาน ≥ 2 รอบ (ดีที่สุด 4) แบบ mapping ปิด โดยเปิด `WALK_FRAMES` → ดึงมาด้วย
   `python scripts/walk_frames.py pull --last` ทีละรอบ → `python scripts/map_check.py --last 4` → ดู `report.png` (แดง = แผนที่มีแต่ไม่มีจริง,
   น้ำเงิน = โต๊ะ/ของที่แผนที่ยังไม่มี, ม่วง = กระจก/ผนังวาดคลาด ไม่ลบเอง) กับ `pictures.jpg` (แต่ละจุดในภาพกล้อง) ·
   อันไหนเป็นคน/ของที่จะย้าย ใส่ `--keep เลข` แล้วรันซ้ำ · บรรทัด "self-check" ต้องขึ้น (เลเซอร์ตรงแผนที่ใหม่ดีกว่าเดิม)
   · อัป `clean.stcm` ขึ้นบอร์ด = ขั้นแยก ทำเมื่อเจ้าของสั่ง: หุ่นอยู่บนแท่น, สำรองแผนที่เดิมก่อน (`GET maps/stcm`), อัปแล้วตั้งตำแหน่งที่แท่น,
     ลองเดินก่อนแล้วค่อย `:save`
   · ถ้า summary บอกว่าข้ามเฟรมเยอะ (เลเซอร์ตรงแผนที่ < 0.40) = ห้องเปลี่ยนมากจนบอร์ดหาตำแหน่งไม่ได้ → ต้องสแกนใหม่ตอนห้องว่างจริงๆ
2. ขับหุ่นไปยืนที่โต๊ะแต่ละตัว หันหน้าตามที่ต้องการ แล้วกด "บันทึกตำแหน่งตอนนี้" ในหน้าคุม
   (กดสองครั้ง) — บันทึกลง `data/events/floor1_event.spots.json` บนหุ่น · deploy ไม่ทับไฟล์นี้
   · หุ่นยังหาตำแหน่งตัวเองไม่ได้ (Q < 50) = บันทึกไม่ได้
3. ลองเดินแต่ละจุดด้วย "ไปที่นี่" ให้ถึงสะอาดอย่างน้อย 2 ครั้ง (หน้าคุมนับให้) —
   ระวังแขนชนขอบโต๊ะ และล้อเก้าอี้ที่อยู่ต่ำกว่าระดับเลเซอร์ (เจอแล้ว 28 ต.ค.)
   · หุ่นเก็บภาพกล้องหัว + ระยะไลดาร์ทุกวินาทีระหว่างเดิน (`WALK_FRAMES`) — หลังลองเดินดูด้วย
   `python scripts/walk_frames.py pull --last` ว่าผ่านใกล้อะไรตรงไหน · ทางเดินของหุ่นควรกว้าง ≥ 1.2 ม. (หุ่นกว้าง 0.70 ม. รวมแขน 0.78)
4. เช็คเน็ตที่จุดจัดงาน — Emma ต้องใช้เน็ตตลอด ควรมีเราเตอร์ 4G สำรอง

## ติดตั้ง (ทำครั้งเดียว)

```
# 1) key ของหน้าคุม: บรรทัด EVENT_CONTROL_KEY=<สุ่มยาวๆ> ใน .env ของ PC แล้ว
python scripts/robot_server.py secrets
python scripts/robot_server.py deploy          # ส่ง board_walk + floor1.json + ไฟล์งาน
# 2) แอป: build -PemmaApp=event แล้วลงคู่กับแอปเดิม
adb install -r -g .tmp/apk/emma-event-20261030.apk
adb shell am start -n com.emma.robot.event/com.emma.robot.control.MainActivity \
    --es server_url https://127.0.0.1:8001 --es ws_token <WS_TOKEN>
# 3) เปิดการเดินเมื่อหุ่นอยู่ในตำแหน่งแล้ว: EVENT_WALK_ENABLED=true ใน data/robot-server/robot.env
python scripts/robot_server.py secrets && python scripts/robot_server.py restart
```

แอปใหม่เริ่มจากค่าว่างทั้งหมด (server, token, สวิตช์ท่าทาง, ท่าแขนที่บันทึกในสตูดิโอ) — ต้องตั้งใหม่ในแอปนี้

## ที่ยังไม่รู้ / รอเจ้าของ

- พิธีเปิดจัดตรงไหน ใช้ทีวีเครื่องไหน (ตอนนี้มีแค่จอห้องมัลติมีเดีย) — เรื่องของพิธีทั้งหมดอยู่ใน [emma-ceremony.md](emma-ceremony.md) · คลิปจริง
- แต่ละฉากต้องทำ/พูดอะไรจริงๆ และมีฉากอื่นอีกไหม
- ชื่องาน กำหนดการ ข้อมูลที่ Emma พูดได้ (`name_th`, `facts_th`)
- Emma ตอบเรื่องโครงการด้วยไหม (ตอนนี้ตอบได้เหมือนห้องขาย) หรือพูดแค่เรื่องงาน
- จำนวนโต๊ะและตำแหน่ง
- เปิดไฟจากหน้าคุม (เจ้าของ 30 ต.ค. "หน้าควบคุมอาจจะมีเปิดไฟ"): ไฟชุดไหน เปิดปิดด้วยอะไรอยู่ตอนนี้ — ระบบมี `set_lights`
  ผ่านรีโมต IR (Broadlink) ของห้องขายที่ 192.168.0.x ซึ่งหุ่น (192.168.1.x) ไปไม่ถึง: ถ้าไฟชั้น 1 ใช้รีโมต IR ต้องมีกล่อง IR ในวงเดียวกับหุ่นแล้วสอนรหัสใหม่
  · เจ้าของ 30 ต.ค.: ระบบคุมไฟ "ยังไม่ได้ทำ" — รอฮาร์ดแวร์ก่อน

**ตัดสินแล้ว:** ภาษาเริ่มต้นในงาน = อังกฤษ (เจ้าของ 30 ต.ค.) — คือกฎเดิม: ยังไม่มีใครคุย Emma พูดฉากเป็นอังกฤษ
ประโยคแรกของแขกกำหนดภาษา และมีเมนูภาษาบนจอ (วัดสด 30 ต.ค.: ฉากก่อนมีคนคุยออกมาเป็นอังกฤษ)

## ข้อจำกัดที่รู้

- หน้าคุมเป็น http ธรรมดาบน Wi-Fi สำนักงาน (แบบเดียวกับจอห้อง `/mirror`): คนในเครือข่ายเดียวกันที่ดักคุกกี้ได้
  ก็กดฉากได้ — ทางหยุดทุกทางยังใช้ได้เสมอ
- ระหว่างหุ่นเดิน ถ้าหน้าคุมปิด หุ่นหยุด — ตั้งใจ (ไม่มีใครดูการเดินนั้น)
- ห้องมัลติมีเดียเป็นจุดอับ Wi-Fi: หน้าคุมอาจหลุดตรงนั้นแล้วหุ่นหยุด
