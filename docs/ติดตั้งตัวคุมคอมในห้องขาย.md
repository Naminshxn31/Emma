# ติดตั้งตัวคุมคอมในห้องขาย (room agent)

เขียนสำหรับคนที่ไปตั้งเครื่องในห้องขาย · ปรับปรุง 25 กันยายน 2026

## นี่คืออะไร

โปรแกรมเล็กๆ ที่รันบนคอมของห้องขายแต่ละห้อง เซิร์ฟเวอร์ของ Emma สั่งงานมาตามสาย LAN
แล้วเครื่องนั้นทำให้ — เปิดโปรแกรม เปิดเว็บ เลื่อนสไลด์ ปิดจอ

**หุ่นไม่ได้คุยกับคอมห้องขายเอง** เซิร์ฟเวอร์เป็นคนคุย หุ่นเป็นแค่ไมค์กับจอ
เพราะงั้นถ้าคอมเซิร์ฟเวอร์สั่งคอมห้องขายได้ = ใช้งานได้ ไม่ต้องรอหุ่น

ไม่มีค่าใช้จ่าย ไม่มีบัญชี ไม่มีคลาวด์ ทุกอย่างวิ่งในวง LAN

## ต้องเตรียมอะไร

- คอมห้องขาย: Windows + Python 3.10 ขึ้นไป
- เครื่องนั้นกับเครื่องเซิร์ฟเวอร์ต้องอยู่วง LAN เดียวกัน (เห็น IP กันได้)

## ขั้นตอน

### 1. สร้างชุดติดตั้ง (ทำบนเครื่องเซิร์ฟเวอร์)

```powershell
python scripts/make_room_package.py "ห้องขาย 1" --out D:\room1
```

ได้โฟลเดอร์ ~1.3 MB พร้อมใช้ **อย่าก๊อปทั้งรีโปไปแทน** สคริปต์นี้มีไว้เพราะสองเหตุผล:

- **ก๊อปน้อยไปแล้วดูเหมือนปกติ** ตัว agent ต้องมี `app/` กับไฟล์ข้อมูลอีกสองไฟล์
  (`data/registry/source_registry.json`, `data/projects/<โครงการ>/project.json`)
  ถ้าขาด เครื่องจะ**บูตขึ้นปกติ ตอบ /health ปกติ ถ่ายจอได้ปกติ** แล้วพังตอนมีคนสั่ง
  "เปิดเว็บ" ครั้งแรก — ต่อหน้าลูกค้า (ตอนนี้ agent เตือนตอนบูตแล้ว แต่สคริปต์กันตั้งแต่ต้น)
- **ก๊อปมากไปอันตรายกว่า** ในรีโปมี `.env` ซึ่งมีคีย์ Gemini กับคีย์ service-role ของ Supabase
  เครื่องห้องขายไม่ควรมีสองอย่างนี้ สคริปต์เขียน `.env` ใหม่ให้ที่มีแค่ค่าของห้องนั้น

### 2. ก๊อปโฟลเดอร์ไปเครื่องห้องขาย แล้วรัน `install.cmd`

ก๊อปทั้งโฟลเดอร์ไป (USB หรือลากผ่าน AnyDesk/Remote Desktop) แล้ว**คลิกขวาที่ `install.cmd` →
Run as administrator** ไฟล์เดียวจบ:

- ติดตั้งไลบรารี (`pip install fastapi uvicorn python-dotenv`)
- เปิดพอร์ตในไฟร์วอลล์ให้
- ก๊อปตัวโปรแกรมไป `C:\ProgramData\EmmaRoomAgent`
- ตั้งให้**เปิดเองทุกครั้งที่ล็อกอิน แบบไม่มีหน้าต่าง** (รันเบื้องหลัง)
- เริ่มทำงานทันที แล้วโชว์ IP ของเครื่องนั้นให้ที่บรรทัดสุดท้าย

**เงื่อนไขเดียว: เครื่องนั้นต้องมี Python ก่อน** ถ้าไม่มี `install.cmd` จะบอกให้ไปลงจาก
python.org (ติ๊ก "Add python.exe to PATH") แล้วรันซ้ำ

**"เบื้องหลัง" = ไม่มีหน้าต่าง ไม่ใช่ซ่อน** ตัวมันอยู่ที่ `C:\ProgramData\EmmaRoomAgent`
เห็นได้, มีชื่อใน Task Scheduler ว่า `EmmaRoomAgent`, เห็น process `pythonw.exe` ใน Task Manager,
และมี `uninstall.cmd` ให้ถอด — โปรแกรมที่สั่งงานคอมได้ต้องหาเจอและปิดได้โดยเจ้าของเครื่องเสมอ
นั่นคือเส้นแบ่งระหว่างเครื่องมือของบริษัทกับแบ็คดอร์

> อยากทดสอบแบบเห็นหน้าต่างก่อน (ยังไม่ตั้ง autostart) ใช้ `start-room-agent.cmd` แทน —
> รันในหน้าต่างที่เปิดค้างไว้ บรรทัดแรกบอกชื่อห้อง/ความสามารถ ถ้าขึ้น `NOT fully installed`
> แปลว่าไฟล์ไม่ครบ

### 3. บอกเซิร์ฟเวอร์ว่าห้องไหนอยู่ IP ไหน

แก้ `data/rooms.json` บนเครื่องเซิร์ฟเวอร์:

```json
{
 "ห้องขาย 1": {"url": "http://192.168.1.51:8777", "token": "ค่าจาก .env ของเครื่องห้องนั้น"},
 "ห้องขาย 2": {"url": "http://192.168.1.52:8777", "token": "ค่าจาก .env ของเครื่องห้องนั้น"}
}
```

**ชื่อห้องต้องตรงกันเป๊ะทั้งสองที่** (ในไฟล์นี้ กับ `ROOM_AGENT_NAME` ของเครื่องนั้น)
และ**ต้องเซฟเป็น UTF-8** ภาษาไทยที่ผ่านการเซฟผิดรหัสจะกลายเป็นคนละคำ แล้วจะหาห้องไม่เจอ
(หาไม่เจอดีกว่าไปเจอห้องผิด — ระบบจะถามกลับ ไม่เดา)

ไฟล์นี้ไม่เข้า git เพราะมี token ของทุกเครื่อง

### 4. ทดสอบ

```powershell
python scripts/room_control.py rooms
python scripts/room_control.py health "ห้องขาย 1"
python scripts/room_control.py do "ห้องขาย 1" list_windows
```

### 5. ถอนออก (บนเครื่องห้องขาย เมื่อไหร่ก็ได้)

รัน `uninstall.cmd` (Run as administrator) — ปิด process, ลบงานใน Task Scheduler, ลบ rule ไฟร์วอลล์
· ไฟล์ที่ `C:\ProgramData\EmmaRoomAgent` ยังอยู่ ลบโฟลเดอร์เองถ้าจะเอาออกหมด

## ไวไฟ สายแลน หรืออินเทอร์เน็ต

**ไวไฟใช้ได้ ไม่ต้องแก้อะไร** ตัว agent ไม่สนว่าเป็นสายหรือไวไฟ มันสนแค่ว่าสองเครื่อง
เห็น IP กันได้ · ที่ทดสอบไปแล้วก็ยิงผ่านที่อยู่ไวไฟของเครื่องเซิร์ฟเวอร์ (192.168.1.83)

**สามเรื่องที่ทำให้ไวไฟ "ไม่ติด" และไม่ได้แปลว่าโค้ดพัง:**

1. **คนละวง** เครื่องเซิร์ฟเวอร์ตอนนี้อยู่สองวงพร้อมกัน — ไวไฟ `192.168.1.83`
   กับสายแลน `192.168.0.2` · คอมห้องขายต้องอยู่**วงเดียวกับ IP ที่ใส่ใน `rooms.json`**
   ถ้าคอมห้องขายอยู่ `192.168.0.x` แล้วชี้ไป `192.168.1.83` จะไม่เจอกัน
2. **ไวไฟสำหรับแขก (guest / AP isolation)** เราเตอร์หลายตัวกันไม่ให้อุปกรณ์ในวงคุยกันเอง
   อินเทอร์เน็ตใช้ได้ปกติแต่เครื่องต่อเครื่องไม่ได้ — ต้องใช้ไวไฟวงพนักงาน
3. **ไฟร์วอลล์** `install.cmd` เปิดพอร์ตให้แล้ว แต่ถ้าลองแบบ manual ด้วย `start-room-agent.cmd`
   ต้องเปิดเอง: `netsh advfirewall firewall add rule name="Emma Room Agent" dir=in action=allow protocol=TCP localport=8777`

เช็คจากคอมห้องขายก่อนว่าถึงกันไหม:

```powershell
Test-NetConnection 192.168.1.83 -Port 8777
```

**ผ่านอินเทอร์เน็ต: ทำได้ แต่อย่าทำแบบเปิดพอร์ตที่เราเตอร์**
ตัว agent พูด HTTP ธรรมดา ไม่ใช่ HTTPS — token จะวิ่งไปแบบอ่านได้ระหว่างทาง
และสิ่งที่เปิดออกไปคือบริการที่**สั่งงานคอมได้** ในวง LAN ของตึกยังพอรับได้ บนอินเทอร์เน็ตไม่ใช่

ถ้าวันหนึ่งต้องข้ามตึกจริงๆ ให้ใช้ Tailscale (ฟรี) ซึ่งโปรเจกต์นี้ใช้อยู่แล้วสำหรับ HTTPS ของไมค์ —
มันทำให้สองเครื่องอยู่วงเดียวกันแบบเข้ารหัส โดยไม่ต้องเปิดพอร์ตไหนออกสู่อินเทอร์เน็ตเลย

## จะให้ห้องนั้นทำอะไรได้บ้าง

แก้ `.env` บนเครื่องห้องนั้น แล้วรีสตาร์ต

| ตั้งค่า | ความหมาย |
|---|---|
| `ROOM_AGENT_ALLOW=all` | เปิดทั้ง 13 อย่าง |
| `ROOM_AGENT_ALLOW=list_windows,press_key,open_in_browser` | เปิดเฉพาะที่ระบุ |
| `ROOM_AGENT_PROGRAMS=chrome,powerpoint` | โปรแกรมที่ห้องนี้เปิดได้ |
| `ROOM_AGENT_PROGRAMS=all` | เปิดอะไรก็ได้ที่ Start Menu หาเจอ |
| `ROOM_AGENT_INPUT=true` | พิมพ์คีย์บอร์ด/คลิกเมาส์จริง |

**`ROOM_AGENT_INPUT` เป็นสวิตช์แยกเสมอ แม้ตั้ง `ALLOW=all`** เพราะการฟังผิดคำเดียว
ที่นี่กลายเป็นการกดแป้นพิมพ์บนเครื่องจริง — ซึ่งจริงพอๆ กันในห้องที่เปิดทุกอย่างไว้แล้ว

**`ROOM_AGENT_PROGRAMS` มีเพราะเคยเกิดจริง** `open_program` หาโปรแกรมจาก Start Menu
คำว่า "cmd" ไปตรงกับ "git cmd" แล้วเปิด shell ขึ้นมาบนเดสก์ท็อป
รายการโปรแกรมที่ติดตั้งไว้ ไม่ใช่รายการที่คนแปลกหน้าหน้าไมค์จะสั่งเปิดได้

## ความปลอดภัย

- ไม่ตั้ง `ROOM_AGENT_TOKEN` = ปฏิเสธทุกคำสั่ง (ไม่ใช่ปล่อยผ่าน)
- token คนละตัวต่อเครื่อง ถ้าเครื่องไหนหลุด เปลี่ยนเฉพาะเครื่องนั้น
- `ROOM_AGENT_HOST=0.0.0.0` ให้เครื่องอื่นเรียกได้ ใช้เฉพาะในวง LAN ของตึก
- ภาพหน้าจอกับ log อยู่ใน `data/room-agent/` ของเครื่องนั้น ไม่ถูกส่งไปไหน และไม่เข้า git
  — ภาพคือ "อะไรก็ตามที่อยู่บนจอตอนนั้น" ควรลบเป็นระยะ
