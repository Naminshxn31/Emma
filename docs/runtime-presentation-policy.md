# M0.3b — Slides / Canva / Documents

ภาพกับข้อความมีสิทธิ์คนละอย่าง `app/presentation_policy.py` คืน `capabilities.display` และ `capabilities.model_text` แยกกัน: slide ต้องมี `source_id`/`project_id` ตรง session และไฟล์อยู่ใน pinned asset manifest จึงคืน asset ID/URL ได้ แต่ title, summary, detail, transcript, script, ask และ metadata อิสระไม่เข้าผลเครื่องมือเมื่อ source ยังไม่ผ่าน customer disclosure. การอนุมัติ source ไม่ทำให้ script draft เป็นบทที่พูดได้; script ยังต้องมี sign-off ของตัวเอง. Trace ที่ส่งให้ provider ไม่สะท้อน metadata ที่ถูกปฏิเสธ.

`search_condo_info` คัดเฉพาะ source ที่ผ่าน approval/disclosure **ก่อน** สร้าง BM25/semantic index และก่อน reranker; ตรวจซ้ำก่อนสร้าง result. `show_slide` ค้นภาพด้วย lexical index ในเครื่องเท่านั้น ข้อความ draft ที่ช่วยหารูปไม่ถูกส่งไป embedding service หรือ model reranker และไม่กลับมาเป็น caption ใน tool result. ดัชนีข้อความกับดัชนีภาพแยกกัน; การเปลี่ยนไฟล์ catalog หรือ project context ทำให้ cache โหลดใหม่. `current_slide()` ตรวจสิทธิ์ซ้ำก่อนคืนสถานะที่ค้างในหน่วยความจำ จึงไม่คืนข้อความที่ถูกถอนอนุมัติหรือสไลด์ของ project ก่อนหน้า. ถ้าหา approved text ไม่พบ ไม่มี fallback ไปยัง draft.

Canva ใช้ measured `canva_pages.json` ของ project จาก server และ design ID ต้องตรงกับ `CANVA_URL` ที่ตั้งไว้; ไม่มี mapping, map ต่างโครงการ/ต่าง design, หรือ page ไม่อยู่ใน slide catalog ของ session ให้หยุด ไม่เดาหมายเลขจาก slide ID. Cache map ผูก project/path/design/content hash; title/description ใน map ไม่ถูกคืนให้ Emma. การตรวจนี้ไม่ได้รับรองว่า Canva remote design ยังมี byte ตรงกับ export ที่ใช้ทำ map; ความถูกต้องของภาพที่จอ render และ ACK เป็นงาน M1.

เอกสารสำหรับลูกค้าใช้ source-level approval เท่านั้น: แต่ละรายการใน print catalogue ต้องมี `source_id=printable_documents`, `project_id` ตรง session, approval/disclosure metadata ตาม M0.2 และ `approval_unit=entire_document`; รายการ mixed หรืออนุมัติเฉพาะ chunk ถูกปฏิเสธทั้ง PDF. กรองก่อนค้นชื่อ, คืนรายการ หรือสั่งพิมพ์ และอ่าน catalogue ใหม่ทุกครั้งเพื่อรับการถอนอนุมัติ. Source จริงใน `data/documents/catalogue.json` ยังไม่มี metadata เหล่านี้ จึงไม่ถูกเปิดให้ลูกค้าโดยงานนี้; ไม่มีการเปลี่ยน draft เป็น approved. `search_my_documents` ใน condo profile ยังคงบล็อกก่อนอ่าน/จัดอันดับ corpus ส่วนตัว.

การทดสอบจำลอง serialized tool result ที่ส่งเข้า provider แล้ว assert ว่าข้อความ sentinel จาก draft/foreign source ไม่อยู่ใน payload. ยังไม่ได้ทดสอบ Canva remote, เอกสารจริงกับเครื่องพิมพ์ หรือ render ACK; M0.3c ยังต้อง sweep adapter อื่น.
