## สถานะ 16 พ.ย. (เหลือหนึ่งอาทิตย์ถึงวันซ้อม 23 พ.ย.)

สรุปจากเอกสารและ CHANGELOG ตามที่เจ้าของถาม *"ตอนนี้หุ่นเป็นยังไงบ้างกับวันงาน ยังขาดอะไรกับเหลืออะไร"* · **ตารางซ้อม 9–13 พ.ย. ข้างล่างยังไม่ได้ทำ** เพราะหุ่นอยู่ชั้น 2 ตามเจ้าของ (12 พ.ย.)

**ลองบนหุ่นจริงแล้ว (ชั้น 2):** ปุ่มเปิดตัว (เสียงอัด มือขึ้นก่อนเสียง ท่านางงามตอนยืน เดินไปข้างหน้า) · ปุ่มกลับแท่นแบบถอยตามแนว ·
หัวหันตามคนพูดก่อน (ขึ้นหุ่น 12 พ.ย. ยังไม่มีใครยืนยันว่าดีขึ้น) · แอปพิธีลงแล้ว บทอนุมัติ 29/30 คิว · หน้าปุ่ม manual ขึ้นหุ่น 14 พ.ย. (ยังไม่มีใครกด)

**ยังไม่เคยลองบนหุ่น (ต้องลงชั้น 1 ก่อน):**
1. การเดินทุกฉากชั้น 1 — จุดของงาน/พิธียังไม่บันทึกที่ชั้น 1 · แผนที่ชั้น 1 ฉบับเติมเฟอร์นิเจอร์ยังไม่อัป · R1–R8 ยังไม่ได้ทำ

3. เดินเข้าหาแขก / เดินวน — ยังเป็น dry-run (ล้อไม่หมุน)
4. เราเตอร์ 4G สำรอง (ห้องมัลติมีเดียเป็นจุดอับ) · Android รีบูตเอง (สาเหตุยังไม่รู้) · แบตทั้งวัน (R14)

**รอเจ้าของ:** ผังโต๊ะงาน (กำหนด 16 พ.ย.) · เลขห้องสาธิต · ทีมจอแก้ LED 500 ม./"มากกว่า 2,500" · เสียงพิธีไทยหรืออังกฤษ ·

ภาษาเริ่มอังกฤษ / สายเปิดค้าง (`STANDING_LINE`) / ปุ่มจับมือแตะเดียว · ท่าโบกมือ ยกแขนขวา-ซ้าย ยังไม่ได้บันทึกในสตูดิโอของแอป Emma Event · งานตั้งแต่ commit ล่าสุดยังไม่ commit

## ตารางซ้อม

ทำทุกข้อบนชั้น 1 ด้วยแอป Emma Event รุ่นใหม่ เปิด `EVENT_WALK_ENABLED` ตอนซ้อม มีคนยืนใกล้ E-stop ทุกครั้ง

### 6–8 พ.ย. เตรียมของ (หลังเปิดหุ่น)

1. ดึงรอบสำรวจ 2 ตามหัวข้อถัดไป
2. `python scripts/robot_server.py secrets` แล้ว `deploy` แล้ว `restart` ตามคู่มือ emma-event-host
3. build แล้วลงแอป: `gradlew assembleDebug -PemmaApp=event` จากนั้น `adb install -r -g ...` แล้ว **build ปกติคืน** (output path เดียวกัน)

### 16 พ.ย. ได้ผังโต๊ะแล้วเดินสำรวจอีกรอบ

เจ้าของ 5 พ.ย.: *"ผังโต๊ะงาน ภายใน 16 พ.ย. ค่อยเดินสำรวจอีกที"* · เดิน `lobby_survey` รอบใหม่ (ห้ามใช้ `--map`) แล้วตรวจแผนที่ตามหัวข้อท้ายเอกสาร ·
เดินจริงตามตำแหน่งโต๊ะในผัง เช็คทางเดินหุ่น ≥ 1.2 ม. · โต๊ะจริงยังไม่เข้าที่ = รอบนี้ดูแค่ห้องและทาง รอบ 23–24 พ.ย. คือรอบที่เห็นโต๊ะจริง

### 16–20 พ.ย. พิธีเปิด

ทำครบก่อนวันซ้อมใหญ่ ทุกข้อหุ่นอยู่กับที่ · ต้องวางคลิปจริง

| ข้อ | ทำ | ผ่านเมื่อ |
