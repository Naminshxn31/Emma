# เขียนคำถามให้หุ่นยนต์ถามลูกค้าระหว่างพรีเซนต์

หุ่นยนต์จะพูดบทของสไลด์นั้นก่อน แล้วถามคำถามที่เขียนไว้ **แล้วหยุดรอ**
พอลูกค้าตอบ มันจะรับคำตอบสั้นๆ แล้วไปสไลด์ถัดไปเอง
ถ้าไม่มีใครตอบภายใน 9 วินาที มันจะไปต่อเองเงียบๆ ไม่ทวงซ้ำ

## เขียนตรงไหน

ไฟล์ `data/slides/index.json` — หาสไลด์ที่ต้องการ แล้วเพิ่มฟิลด์ `ask_th`

```json
{
  "id": "ew-005",
  "title_th": "โซนพัทยา",
  "script_th": "พัทยาแบ่งเป็นสี่โซนหลักคือ พัทยาเหนือ พัทยากลาง พัทยาใต้ และจอมเทียนค่ะ",
  "ask_th": "แล้วคุณลูกค้าเคยมาเที่ยวจอมเทียนไหมคะ ประทับใจตรงไหนบ้าง"
}
```

สไลด์ไหนไม่ใส่ `ask_th` ก็ทำงานเหมือนเดิม — พูดจบแล้วไปต่อทันที
แก้ไฟล์แล้วรีสตาร์ตเซิร์ฟเวอร์ ไม่ต้องแตะโค้ด

## กติกาในการเขียน

**อย่าใส่ทุกหน้า** ตอนนี้ใส่ไว้ 4 หน้าจาก 59 (หน้า 5, 26, 40, 55)
ถ้าใส่ทุกหน้าจะกลายเป็นการสัมภาษณ์ ไม่ใช่การพรีเซนต์ — และทัวร์จะยาวขึ้นมาก
ประมาณทุก 10-15 หน้ากำลังดี

**ถามให้ตอบได้มากกว่า ใช่/ไม่ใช่** "เคยมาเที่ยวจอมเทียนไหมคะ" จบที่ "ไม่เคย"
เติม "ประทับใจตรงไหนบ้าง" ต่อท้าย บทสนทนาถึงจะเดินต่อ

**ต้องเกี่ยวกับหน้านั้นจริงๆ** คำถามที่ใช้กับหน้าไหนก็ได้ คือคำถามที่ควรตัดทิ้ง
หน้าสปาถามเรื่องซาวน่า หน้าห้องพักถามว่าอยู่กันกี่คน

**สั้น** ไม่เกิน 80 ตัวอักษร คำถามยาวๆ ฟังแล้วจำไม่ได้ว่าถามอะไร

**ลงท้ายให้สุภาพ** คะ/ครับ — เพราะมันถูกพูดออกมา ไม่ใช่อ่าน

มีเทสต์ (`test_the_seeded_questions_are_open_ended_and_on_topic`) เช็คสองข้อหลัง
ให้อัตโนมัติ ถ้าเขียนผิดกติกาจะแดงตอนรันเทสต์

## ที่ตั้งใจให้เป็นแบบนี้

**หุ่นยนต์ไม่คิดคำถามเอง** คนเขียนอย่างเดียว — หุ่นยนต์ที่แต่งบทคุยเล่นเองในห้องขาย
คือความเสี่ยง และคำถามที่ดีมักเป็นคำถามที่ใช้ได้แค่กับหน้านั้นหน้าเดียว

**ตอบแล้วมันจะไม่บ่ายเบี่ยง** ปกติหุ่นยนต์ถูกสั่งห้ามคุยนอกเรื่องเด็ดขาด
แต่ถ้ามันเป็นฝ่ายถามก่อน มันจะรับคำตอบอย่างเป็นกันเองได้ 1 ประโยค
ไม่ขอโทษว่านอกเรื่อง — แต่ยังห้ามแนะนำร้านอาหารหรือสถานที่อื่นอยู่

**ปรับเวลารอได้** `TOUR_ASK_GRACE_S` ใน `.env` (ตอนนี้ 9 วินาที)
ถ้าลูกค้ากลุ่มไหนคิดนาน เพิ่มได้ — แต่ถ้าคนไม่ค่อยคุย ลดลงจะลื่นกว่า
นาฬิกาหยุดทันทีที่มีคนเริ่มพูด ไม่ใช่ตอนถอดเสียงเสร็จ ลูกค้าที่พูด
"เอ่อ... เคยมาค่ะ ตอนเด็กๆ" เลยไม่โดนตัดกลางประโยค
