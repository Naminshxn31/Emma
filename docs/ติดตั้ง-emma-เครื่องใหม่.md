# ติดตั้ง Emma บนคอมเครื่องอื่น

คู่มือย้าย/ลงใหม่ทั้งระบบ ใช้เวลา ~15 นาที (ไม่รวมดาวน์โหลด)

## สิ่งที่เครื่องใหม่ต้องมี

- Windows 10/11 + ไมโครโฟน + ลำโพง
- Python 3.12 ขึ้นไป (แนะนำ 3.12 — 3.14 ใช้ได้แต่บางไลบรารีเพิ่งตามมา)
- Git
- อินเทอร์เน็ต (Gemini ทำงานผ่าน API — เสียงพูดต้องออกเน็ต ยกเว้น wake word ที่ฟังในเครื่อง)

## ขั้นตอน

```bash
# 1. โคลนโค้ด
git clone <URL ของ repo นี้> condo-voice
cd condo-voice

# 2. สร้าง venv แล้วลงไลบรารี
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

# 3. ตั้งค่า — สร้าง .env จากตัวอย่าง
copy .env.example .env
```

แก้ `.env` อย่างน้อย 4 บรรทัดนี้:

```ini
GEMINI_API_KEY=ใส่คีย์จาก aistudio.google.com/apikey
ASSISTANT_PROFILE=emma        # ผู้ช่วยส่วนตัว (ไม่ใส่ = โหมดห้องขาย)
WAKE_ENABLED=true             # เรียก "Emma" แทนกดปุ่ม
AUTO_CONNECT=true             # เปิดหน้าแล้วต่อเลย + วางเองเมื่อเงียบ
IDLE_TIMEOUT_S=120            # เงียบ 2 นาที = วางสาย ประหยัด quota
```

```bash
# 4. โหลดโมเดล wake word (ครั้งเดียว ~15MB)
.venv\Scripts\python scripts\fetch_wake_model.py

# 5. รัน
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

เปิดเบราว์เซอร์ไป `http://localhost:8000` → อนุญาตไมโครโฟน → พูด "Emma"

## ข้อมูลที่ควรก๊อปตามไปด้วย (ถ้าย้ายเครื่อง)

ของพวกนี้ **ไม่อยู่ใน git** (จงใจ — เป็นข้อมูลส่วนตัว) ต้องก๊อปเอง:

| ไฟล์/โฟลเดอร์ | คืออะไร | ถ้าไม่ก๊อป |
|---|---|---|
| `data/memory.json` | ความจำถาวรของ Emma | เริ่มจำใหม่จากศูนย์ |
| `data/reminders.json` | เตือน/จับเวลาที่ตั้งค้างไว้ | นัดที่ตั้งไว้หาย |
| `data/personal-docs/` | เอกสารที่ให้ค้น (เว็บบริษัท ฯลฯ) | รัน `import_website.py` ใหม่ได้ |
| `.env` | คีย์และการตั้งค่า | ตั้งใหม่ตามข้อ 3 |

⚠️ `.env` มี API key — ห้ามส่งผ่านช่องทางสาธารณะ ห้าม commit

## ของที่ผูกกับเครื่อง/สถานที่ (ตั้งใหม่ต่อเครื่อง)

- **ไมโครโฟน**: เบราว์เซอร์จะขอสิทธิ์ครั้งแรก — กด Allow แล้วจบ
- **Broadlink (ไฟ/แอร์)**: ฮับผูกกับ*เครือข่าย*ไม่ใช่เครื่อง — เครื่องใหม่ในบ้านเดิม
  รัน `python scripts/find_broadlink.py --save` ครั้งเดียวพอ
  บ้านใหม่ = ต้องมีฮับของที่นั่น + สอนรหัสรีโมทของเครื่องใช้ไฟฟ้าที่นั่น
- **เว็บบริษัท/เอกสาร**: `python scripts/import_website.py <url>` ดูดใหม่ได้เสมอ

## ปัญหาที่เจอบ่อย (เจอมาแล้วทั้งหมด)

| อาการ | สาเหตุ/ทางแก้ |
|---|---|
| เปิดหน้าแล้วยังเห็นหน้าเลือกเสียง | แคชหน้าเก่า — Ctrl+Shift+R หนึ่งครั้ง / เช็คว่าเหลือแท็บเดียว |
| เรียก "Emma" ไม่ตื่น | ปรับใน .env: `WAKE_BOOST=3.0` ขึ้น หรือ `WAKE_THRESHOLD=0.15` ลง |
| ตื่นเองบ่อยทั้งที่ไม่ได้เรียก | `WAKE_THRESHOLD` ขึ้น (เช่น 0.3) |
| พอร์ต 8000 ไม่ว่าง | มี uvicorn เก่าค้าง — ปิด process python ตัวเก่า |
| สั่งไฟ/แอร์ "ล้มเหลว" | ฮับไม่อยู่/IP เปลี่ยน — `python scripts/find_broadlink.py --save` |
| เซสชันตายทันทีที่ต่อ | อย่าลืม: เครื่องใหม่ไม่มี CANVA_URL = ปกติ (แก้แล้วในโค้ด) แต่ถ้าเจอให้ pull ล่าสุด |

## เช็คว่าลงครบ

```bash
.venv\Scripts\python -m pytest tests/ -q   # ควรเขียวทั้งหมด (~3 นาที)
```

เทสต์ที่ skip พร้อมเหตุผล = ของ optional ที่เครื่องนั้นไม่มี (เช่น โมเดล wake ยังไม่โหลด) — อ่านเหตุผลใน skip แล้วตัดสินใจว่าต้องมีไหม
