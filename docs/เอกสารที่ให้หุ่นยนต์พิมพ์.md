# เอกสารที่ให้หุ่นยนต์พิมพ์

หุ่นยนต์ **ไม่สร้างเอกสารเอง** มันพิมพ์ได้เฉพาะไฟล์ที่ทีมขายเตรียมไว้และใส่ชื่อในรายการเท่านั้น
คนที่เตรียมไฟล์เป็นเจ้าของเนื้อหาทั้งหมด

## วิธีเพิ่มเอกสาร

1. วางไฟล์ PDF ไว้ใน `data/documents/`
2. เพิ่มรายการใน `data/documents/catalogue.json`
3. รีสตาร์ตเซิร์ฟเวอร์

```json
{
  "name": "โบรชัวร์โครงการ",
  "file": "brochure.pdf",
  "about": "ข้อมูลโครงการโดยรวม",
  "aliases": ["โบรชัวร์", "เอกสารโครงการ", "แผ่นพับ", "brochure"]
}
```

`aliases` คือคำที่ลูกค้าอาจใช้เรียก ใส่ให้ครบทั้งไทยและอังกฤษ ยิ่งใส่มากยิ่งจับได้แม่น

**วางไฟล์เฉยๆ ไม่พอ** ต้องมีชื่อในรายการด้วย — กันไม่ให้ไฟล์ที่ใครสักคนก๊อปมาวางไว้
กลายเป็นของที่หุ่นยนต์แจกลูกค้าได้

## ที่ตั้งใจให้เป็นแบบนี้

**พิมพ์ได้เฉพาะที่มีในรายการ** ถ้าลูกค้าขอสิ่งที่ไม่มี หุ่นยนต์จะบอกว่ามีอะไรบ้าง
**ไม่พิมพ์ของที่ใกล้เคียงที่สุดแทน** — กระดาษที่ออกมาแล้วเอาคืนไม่ได้ และลูกค้าที่ขอ
ตารางราคาแล้วได้โบรชัวร์ คือลูกค้าที่ได้รับคำตอบผิดบนกระดาษที่มีโลโก้โครงการ

**จำกัดจำนวนชุด** ค่าเริ่มต้น 3 ชุดต่อครั้ง (`PRINT_MAX_COPIES` ใน `.env`)
เพราะการฟังผิดที่นี่กลายเป็นจำนวนกระดาษ — ใน log จริงเคยมีประโยคที่ถอดเสียงได้ว่า
"อะไรนะ 50"

**พิมพ์ไม่สำเร็จจะไม่บอกว่าสำเร็จ** กระดาษหมด เครื่องปิด ไม่มีเครื่องพิมพ์ —
หุ่นยนต์จะบอกตรงๆ ว่าเครื่องพิมพ์มีปัญหา ไม่ใช่บอกว่าพิมพ์ให้แล้วทั้งที่ถาดว่าง

**ไฟล์ต้องอยู่ในโฟลเดอร์นั้นจริงๆ** ถ้า `file` ชี้ออกนอกโฟลเดอร์ (เช่น `../../.env`)
รายการนั้นจะถูกข้ามพร้อม warning

## ตั้งค่า

```
DOCUMENTS_DIR=data/documents
PRINT_ENABLED=true
PRINTER_NAME=            # ว่าง = ใช้เครื่องพิมพ์เริ่มต้นของเครื่อง
PRINT_MAX_COPIES=3
```

## ถ้าพิมพ์ไม่ออก

**"Windows ไม่มีโปรแกรมที่ผูกกับไฟล์ PDF"** — Windows สั่งพิมพ์ PDF ผ่าน shell ได้
ก็ต่อเมื่อมีโปรแกรมผูกกับนามสกุล `.pdf` อยู่ ซึ่งเครื่องที่เพิ่งลง Windows ใหม่
หรือเครื่องที่ใครก็ได้เป็นคนเซ็ตมักจะไม่มี

แก้ได้สองทาง:

| ทาง | เหมาะกับ |
|---|---|
| ตั้งโปรแกรมเริ่มต้นของ `.pdf` ใน Windows Settings | เครื่องส่วนตัวที่มีคนดูแล |
| **ตั้ง `PDF_PRINT_EXE` ชี้ไปที่ SumatraPDF.exe** | **เครื่องในห้องขาย** |

ทางที่สองดีกว่าสำหรับ kiosk เพราะไม่พึ่งการตั้งค่าที่หายไปตอนล้างเครื่อง
SumatraPDF ~10MB พกพาได้ ไม่ต้องติดตั้ง — โหลดจาก sumatrapdfreader.org
แล้วใส่ path ลง `.env`

```
PDF_PRINT_EXE=C:\tools\SumatraPDF.exe
```

## ที่ยังไม่ได้ทดสอบ

**การพิมพ์ออกเครื่องจริงยังไม่เคยรัน** — โค้ดส่งงานผ่าน PowerShell บน Windows
แต่ผมทดสอบกับเครื่องพิมพ์จริงไม่ได้ ทุกอย่างที่เหลือ (การเลือกเอกสาร จำกัดจำนวน
กันไฟล์นอกโฟลเดอร์ การรายงานเมื่อพิมพ์ไม่สำเร็จ) ทดสอบครบแล้ว

ลองสั่งพิมพ์จริงหนึ่งครั้งแล้วดู log บรรทัด `print` ใน `data/logs/`
