# Emma — ท่าพักมือห้อยข้างตัว

สถานะ **draft / รอตรวจรูปทรง** ตามภาพ FULL CHARACTER VIEWS ที่ผู้ใช้เลือก

ยึดภาพมือระยะใกล้ล่าสุดเป็นเกณฑ์: **4 นิ้วรวมโป้ง (โป้ง 1 + นิ้วอ้วนมนอีก 3)** ฝ่ามือหนานุ่มแบบถุงมือ ท่ายังคงห้อยข้างลำตัวตามภาพก่อนหน้า

- `EMMA_REST_POSE.blend`: โมเดลสามมิติท่าคงที่ มือห้อย นิ้วโค้งผ่อนคลาย ข้อมือและแขนสั้น
- `validation/`: ภาพหน้า เฉียง ข้าง หลัง และภาพขยายมือจากโมเดลจริง
- `model-audit.json`: ผลตรวจผิวมือและการคงตำแหน่งจุดของแกนตัวเดิม
- `HAND_CONSTRUCTION_GUIDES`: collection ที่ซ่อนไว้ เก็บชิ้นต้นทางก่อนรวมผิวมือสำหรับแก้ทรง

ใช้แกนตัวจาก `client/assets/emma-3d-lab/emma.blend` ที่เฟรม 1 คงพิกัดผิวหัว ใบหน้า ลำตัว คอ อกและวงฐานที่ประเมินแล้ว ปรับเฉพาะแขนและมือในไฟล์ใหม่ ไม่เปลี่ยน `head-match` หรือไฟล์ต้นทาง และไม่เพิ่ม rig/animation

ภาพล่าสุดกำหนดท่ามือ ส่วนภาพเดิม `client/assets/emma/emma-pose-library-reference-v1.png` ใช้ดูรายละเอียดประกอบเท่านั้น ภาพเฉียงไม่ใช่ด้านข้าง 90 องศาที่สอบเทียบได้ ความหนามือ นิ้วที่ถูกบัง และโครงข้อมือยังเป็นการตีความ ไม่ถือว่าอนุมัติรูปทรงทั้งตัวแล้ว

สร้างซ้ำจากรากโปรเจกต์:

```powershell
& '.tmp/emma-3d-tools/blender-4.5.3-windows-x64/blender.exe' --background --python scripts/build-emma-rest-hands.py -- --render
```

ภาพ `front/side/back` ใช้กล้อง orthographic ก้มเล็กน้อยในระดับเดียวกับกล้องเดิม ส่วน `quarter` เป็นมุมเฉียงเพื่อดูนิ้ว จึงเป็นภาพรีวิว ไม่ใช่ผลวัดความตรงกับต้นแบบ 90 องศา

ผลตรวจจริงด้วย Blender 4.5.3 LTS:

- สร้างและเปิดไฟล์ Blender ซ้ำได้ มือข้างละ 52,152 vertices เป็นผิวเชื่อมต่อชิ้นเดียว ไม่พบ nonmanifold edges และพิกัดทุกจุดเป็น finite
- พิกัดแกนตัว 23 ชิ้นก่อน–หลังต่างสูงสุด 0.0; มือซ้าย–ขวาสะท้อนตรงกัน ต่างสูงสุด 0.0
- armatures 0, actions 0; ชิ้นต้นทางของมือซ่อนจาก render; SHA-256 ของไฟล์ lab ต้นทางไม่เปลี่ยน
- เรนเดอร์และตรวจภาพหน้า เฉียง ข้าง หลัง และมือระยะใกล้ครบ 5 ภาพ เห็นนิ้วโป้งกับนิ้วหลัก 3 นิ้วในมุมขยาย และช่องปลายนิ้วในมุมข้าง
- Python compile และ `git diff --check` ผ่าน

เป็นผลตรวจโครงสร้างและภาพท่าพัก ไม่ใช่การรับรองความเหมือนทั้งตัวหรือการอนุมัติแบบจากเจ้าของ
