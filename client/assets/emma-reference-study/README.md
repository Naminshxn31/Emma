# Emma — แกะแบบจากภาพก่อนปั้น

รอบนี้เป็นงานออกแบบจากภาพอ้างอิง แยกชิ้นและเก็บเส้นขอบสำหรับขึ้นรูปภายหลัง ยังไม่ใช่โมเดล 3D รุ่นใหม่ และไม่เปลี่ยนไฟล์ของ 3D lab เดิมหรือ Rive/ระบบเสียง

เลือกชิ้น → สลับ **ภาพต้นแบบ / ซ้อนเส้น / เฉพาะเส้น** ปิด–เปิดเส้นแต่ละชั้น ขยายภาพ หรือดูจุดอ้างอิงได้ เส้นประคือแนววางโครงที่เสนอ เส้นทึบคือขอบที่ใช้ศึกษา สีเติมในโหมดเฉพาะเส้นแยกพื้นที่ผิว ไม่ใช่วัสดุหรือแสงของโมเดล

## ต้นฉบับและวิธีแกะ

ใช้ `../emma/emma-pose-library-reference-v1.png` ขนาด 1501 × 1008 ซึ่งมีภาพชุดเดียวกับภาพแนบของผู้ใช้ หน้าเว็บแสดงไฟล์เดิมผ่าน SVG viewBox ไม่แก้พิกเซล ไม่ยืดชิ้นส่วน และไม่สร้างภาพต้นแบบใหม่

SHA-256: `f360f4d50a276f5715e6c73e45d4d487fe19364dd1ab77d70a30856b9a182878`

- ภาพใหญ่: ใช้ดูขอบหน้าขาว คาง ความกว้างโครเมียมและมือแบ
- ภาพหน้าตรงเล็ก: ใช้เทียบสัดส่วนรวม ตำแหน่งตา ลำตัว คอ ไหล่ มือพัก และวงฐาน
- ภาพ 3/4 และหลัง: ใช้ยืนยันการมีความลึกและแยกพื้นผิว ภาพกลางไม่ใช่มุมด้านข้าง 90 องศา

ส่วนใหญ่เป็นเส้น Bezier ที่เดินตามขอบที่มองเห็น ตาและมือพักเก็บ polygon จากบริเวณเข้ม/สว่างของพิกเซล แล้วตรวจซ้อนภาพ บันทึก ROI และ threshold ใน `method` ของแต่ละส่วนใน JSON ขอบโคนมือที่ถูกเบ้าบังเป็นแนวแบ่งชิ้นที่เลือกใช้ ไม่ใช่รอยต่อที่กู้คืนได้จากภาพ วงฐานแยกแกนสว่างออกจาก bloom ด้วยระดับความสว่างอ้างอิงแล้วทำเส้นโค้งเรียบ

## สิ่งที่แยกไว้

| ลำดับ | ชิ้น/กลุ่ม | จุดที่ต้องรักษาเวลาขึ้นโมเดล |
| --- | --- | --- |
| 01 | หัว · โครเมียม · คาง | โครเมียมเป็นพื้นที่กว้างเชื่อมข้างหัวถึง W มีความกว้างเปลี่ยนตามแนว; ผิวขาวสองพื้นที่อาจมีเปลือกร่วมใต้กรอบ |
| 02 | ตา | เสี้ยวมนพอง ระดับตาประมาณ 51–53% ของความสูงหัวจากภาพหน้าตรง |
| 03 | คอ | สั้นและซ่อนอยู่ระหว่างหัวกับลำตัว |
| 04 | ลำตัว/แกนกลาง | หยดน้ำกลับหัว ปลายมน หน้าขาวแยกจากเปลือกและเบ้าไฟ |
| 05 | ไหล่ | เบ้าสั้นชิดลำตัว แยกวง cuff กับเบ้าติดตัว ไม่ตีความทุกเส้นสะท้อนเป็นแหวน |
| 06 | มือพัก | ฝ่ามืออวบหันข้าง นิ้วซ้อนกัน รักษาช่องเว้าข้างนิ้วโป้ง |
| 07 | มือแบ | ใช้ตรวจมวลมือเดียวกับท่าพัก ภาพมี perspective และการบังนิ้ว |
| 08 | วงฐาน | ขนาดเนื้อวงแยกจากความฟุ้งของแสง |

ความคลาดเคลื่อนที่พบจากโมเดลก่อนหน้า: ตาอยู่สูงเกินไป ขอบยิ้มอ่านเป็นท่อแทนแผ่นโครเมียมกว้าง เบ้าไหล่เปิดเผยเป็นปล้อง และมือพักแบเข้ากล้องมากเกินไป ข้อสังเกตเหล่านี้เป็นเป้าหมายแก้โมเดลครั้งต่อไป ไม่ได้หมายความว่า SVG ชุดนี้เป็น mesh ที่แก้ปัญหาเหล่านั้นแล้ว

## ลำดับขึ้นชิ้นส่วนหลังแผ่นแกะแบบ

1. เริ่มเฉพาะหัวเปล่า: เทียบ silhouette และความลึกในมุมหน้า/3⁄4/หลัง แล้วเพิ่มพื้นที่หน้าขาว–คางและกรอบ W โดยตรวจขอบซ้อนบนมุมกล้องที่ตรงกัน
2. ใส่ตาหลังรูปหัวคงที่ ตรวจด้วยวัสดุเรียบก่อนแสงเงา
3. ค่อยทำลำตัวกับคอ โดยคงสัดส่วนต่อความกว้างหัว
4. ทำไหล่และมือข้างเดียวให้ท่าพักตรงแบบ แล้วจึงตรวจแบ/กำด้วยมือชิ้นเดิม
5. จูนวัสดุและแสงหลังตรวจรูปทรง จากนั้นค่อยเชื่อม rig และทดสอบท่าต่อเนื่อง

ภาพอ้างอิงไม่ใช่ orthographic blueprint: ไม่มีด้านข้าง 90° ไม่มีด้านใต้ และไม่มีโครงข้อภายในครบ สัดส่วนที่แสดงเป็นค่าประมาณของภาพฉาย รายละเอียดและจำนวนปลายนิ้วในบางภาพอ่านได้ไม่เท่ากัน จึงยังต้องตัดสินใจตอนสร้างมือจริง ไม่รับรองความเหมือนทุกด้านหรือความถูกต้องทางกลจากภาพนี้

## สร้างไฟล์เส้นใหม่

```powershell
python scripts/build-emma-reference-study.py
```

แก้พิกัดต้นฉบับในสคริปต์ แล้ว build `reference-map.json` และ `parts/*.svg` ใหม่ ใช้ Python standard library เท่านั้น สคริปต์ตรวจ hash/ขนาดรูปต้นฉบับก่อนเขียน เพื่อป้องกันเส้นพิกัดเดิมถูกใช้กับภาพที่เปลี่ยนไป

`parts/*.svg` เป็นเวกเตอร์ในพิกัดภาพต้นฉบับ ไม่มีภาพฝังอยู่ เหมาะใช้เป็นเส้นประกอบการปั้น ต้องแก้ perspective และกำหนดความลึกก่อนนำไปสร้างผิวสามมิติ ห้ามประกอบ SVG จากคนละมุมภาพเข้าด้วยกันแล้วถือว่าเป็น turnaround สมมาตร

ภาพตรวจ Chrome และผลตรวจปุ่มอยู่ใน `build/` ซึ่งไม่รวมใน Git สถานะงานยังเป็น draft ไม่มีการเปลี่ยนเป็น approved อัตโนมัติ
